1

阿里云账号：注册、实名、充值

约 30 分钟
https://www.aliyun.com
路径：手机号注册 → 右上角头像 实名认证 → 右上角 费用中心 充值
  1. 用手机号注册，登录阿里云。
  2. 右上角头像 → 「实名认证」→ 选 个人 → 支付宝扫脸，约 1 分钟通过。
  3. 右上角 → 「费用中心」→ 充值 1000 元，后面买机器和域名直接扣。
!
个人实名就能买香港 ECS 和 .com 域名，不需要公司；后面要开发票、升级企业主体再认证企业。主账号密码不要给任何人，包括我。

3

安全组：放行 80 和 443

约 5 分钟
路径：ECS 控制台 → 实例列表 → 点实例名 → 安全组 → 配置规则 → 入方向 → 手动添加
端口协议授权对象用途
22TCP你的公网 IP团队 SSH 登录服务器
80TCP0.0.0.0/0网站访问 + HTTPS 证书验证
443TCP0.0.0.0/0HTTPS
!
不要开 3000、7860、3306、6379——网站走 nginx 转发，这些端口不该暴露。不知道自己的 IP：搜「我的 IP」，或临时把 22 设成 0.0.0.0/0，部署完再收紧。
4

买 OSS，建两个桶

约 10 分钟
https://oss.console.aliyun.com
路径：创建 Bucket，按下面填
选项公共读桶（图床）私有桶（备份）
桶名novai-assets-加你的后缀novai-backup-加你的后缀
地域中国香港中国香港
读写权限公共读私有
版本控制开启（防误删）开启
其他默认默认
  • 桶名只能小写字母、数字、中划线，全球唯一，被占就换个后缀。
  • 公共读 = 拿到图片链接的人都能看（这是 AI 能读取素材的前提）；文件名是 32 位随机串，别人猜不到、也遍历不了。
  • 私有备份桶只给程序用，外网拿不到。
→
发我：两个桶名。
5

开一个「只能管 OSS」的小号

约 10 分钟
https://ram.console.aliyun.com
路径：用户 → 创建用户 → 建 AccessKey → 权限管理 → 新增授权
  1. 左侧「用户」→「创建用户」，登录名称填 novai-deploy。
  2. 访问方式 只勾「OpenAPI 调用访问」，不要勾控制台访问。
  3. 创建完成后点进这个用户 →「创建 AccessKey」→ 复制 AccessKey ID 和 AccessKey Secret（Secret 只显示一次）。
  4. 同页「权限管理」→「新增授权」→ 搜索 AliyunOSSFullAccess → 选中 → 确定。
→
发我：AccessKey ID + Secret。单独发，别发群、别截图。这个小号只能读写 OSS，动不了服务器；部署完随时能在控制台禁用。
6

买域名并实名

30 分钟 + 审核 1–2 天
https://wanwang.aliyun.com
路径：搜域名 → 加入清单 → 结算 → 填 信息模板 做域名实名
  1. 搜一个你喜欢的 .com，加入清单，结算，买 1 年。
  2. 结算时填「信息模板」：姓名 + 身份证号 + 手机号，提交 域名实名。
  3. 实名审核 1–2 个工作日，通过前不能解析——所以这一步尽早做，别拖到最后。
✓
香港服务器不需要 ICP 备案，买 .com 最省事。别买奇怪后缀，也不要用别人送的域名（实名不是你就控制不了）。

我部署，你等

约 1 天
  • 装 Ubuntu 环境、Python 3.11、nginx、开机自启。
  • 代码放 /opt/novai，数据目录 /opt/novai/cloud-data（全新空目录，不碰你本地数据，试用期不同步）。
  • nginx 反向代理 + 免费 HTTPS 证书（自动续期）。
  • 接 OSS：上传素材落 OSS、生成结果立刻转存 OSS、素材库和 AI 引用都用 OSS 地址。
  • 每日备份到私有桶；磁盘 / 余额 / 报错告警。
  • 给你管理员初始账号和网址。
✓
这期间不需要你操作；有问题我直接说。
10

手机验收 + 发邀请码

约半天

用手机 4G（别用公司 Wi-Fi，避免误判），逐条过：

  1. 打开 https://你的域名，地址栏有小锁，没有「不安全」提示。
  2. 用管理员账号登录，生成一张图。
  3. 刷新页面，图还在。
  4. 复制图片地址，应该长这样：https://novai-assets-xxxx.oss-cn-hongkong.aliyuncs.com/...（不是服务器 IP 开头的路径）。
  5. 换个浏览器注册普通账号（用邀请码），确认看不到管理员的画布和素材。
  6. 让我重启一次服务器，网站 1 分钟内自动恢复。

全部通过后：后台生成 6 位数字邀请码（一码一次、7 天有效），发 3–5 个朋友试一周。

常见坑

没实名

买不了 ECS、域名解析会被锁。先做实名再买。

域名实名要 1–2 天

通过前解析不了，先买先审，别拖到最后。

香港 4 核 8G 可能没货

先买 2 核 4G 跑起来，后面随时能升配。

带宽别选固定

按使用流量便宜得多，图片走 OSS 后 ECS 流量很小。

安全组别开 3000

网站只走 80/443，其他端口不该暴露。

公共读图床

拿到链接的人都能看图；路径随机不能遍历，但敏感图别传。

主账号 AccessKey 不能外发

只给 OSS 权限的小号，部署完可禁用。

OSS 桶名全球唯一

被占就换后缀，不用纠结。

别用大陆 CDN 加速 OSS

那要备案；香港不需要。

密码 / 密钥单独发

用私聊或密码管理器，事后可改可停。
