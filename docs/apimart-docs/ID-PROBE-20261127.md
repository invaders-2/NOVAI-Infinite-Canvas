## 三档结论

### 确定可用（0 个）
无。全部 9 个都没拿到 200。

### 确定不可用（7 个）
- **400 `model_not_available`（6 个）**：`deepseek-r1-250528`、`deepseek-v3.2-exp`、`deepseek-v3-0324`、`gpt-5-chat-latest`、`gpt-5.2-codex`、`seedance-1-5-pro`。上游原话是「The model `X` is no longer available. Please choose another model.」——**不是参数错、不是权限错，是这条 ID 已经下线**。和 404 的区别值得记一笔：**400 `model_not_available` = 曾经上线过、现已下线；404 `model_not_found` = 平台认不出这个名字**。
- **404 `model_not_found`（1 个）**：`gemini-2.5-flash-lite`，原话「The model `gemini-2.5-flash-lite` does not exist. Please check the model name.」——**确定不存在**。
- 这 7 个全部没有返回 `usage`，未产生费用。

### 仍未知（2 个）
- `gemini-2.5-pro`、`gemini-2.5-flash`：都是 **HTTP 503**，body 里 `error.code` 写的是 `model_not_found`，但 `error.message` 是「Please wait and try again later. Thank you for your patience!」。**message 说明这是上游渠道/容量瞬时不可用，不是"模型不存在"**（同一批里真正不存在的 lite 走的是 404 + "does not exist"）。按本次「每个 ID 只发一次」的约束，**单次 503 不足以下结论**——可能只是排队/限流，也可能是模型挂着但没可用渠道。
- **建议**：另派一次重试（间隔几秒、最多 2-3 次），若持续 503 再按「不可用/无渠道」处理；本轮不下判断。
