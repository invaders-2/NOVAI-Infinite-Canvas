# 服务器搭建详细操作手册（Boss 版）

> 适用：NOVAI 云端版 · 阿里云香港 ECS + OSS 图床 + 域名 + HTTPS。
> 分工：**采购、实名、付款、验收由你点；装环境、部署、配置、备份、监控由团队做。**
> 每一步都写了网址和要填什么；你只需要照着点，把标了「发我」的东西给我。

## 2. 买云服务器 ECS（10 分钟）

**网址：https://ecs.console.aliyun.com**

路径：左侧「实例」→ 上方「创建实例」→ 进入购买页。

| 选项 | 选什么 | 说明 |
|---|---|---|
| 付费模式 | **包年包月**，1 个月 | 比按量便宜，先试一个月 |
| 地域 | **中国香港** | 必须是香港；选错要重买 |
| 可用区 | 默认（随机分配） | 不用管 |
| 实例规格 | **4 核 8G**（通用型 g8i / g7，或经济型 e） | 没货就选 2 核 4G，先跑起来 |
| 镜像 | 公共镜像 → **Ubuntu 22.04 64 位** | 不要选 Windows |
| 系统盘 | **ESSD 云盘 100 GiB** | 默认 40G 不够，改成 100 |
| 数据盘 | 不加 | 数据放 OSS |
| 公网 IP | 勾选「分配公网 IPv4 地址」 | 不勾就没有公网 |
| 带宽计费 | **按使用流量**，峰值 10 Mbps | 别选固定带宽，贵 |
| 安全组 | 新建安全组，默认 | 稍后第 3 步再补规则 |
| 登录凭证 | **自定义密码**，设一个强密码并记下来 | 推荐密码，比密钥对省事 |
| 购买时长 | 1 个月，自动续费先不勾 | |
| 数量 | 1 台 | |

勾协议 → 「确认订单」→ 支付。

**买完做什么：** 回到实例列表，找到这台机器，记下「**公网 IP**」（形如 47.x.x.x）。

## 3. 配安全组：放行 80 和 443（5 分钟）

路径：ECS 控制台 → 实例列表 → 点实例名 → 「安全组」标签 → 「配置规则」→ 入方向 → 「手动添加」。

| 端口 | 协议 | 授权对象 | 用途 |
|---|---|---|---|
| 22 | TCP | 你的公网 IP（查 IP 搜「我的 IP」） | 团队 SSH 登录 |
| 80 | TCP | 0.0.0.0/0 | 网站 + 证书验证 |
| 443 | TCP | 0.0.0.0/0 | HTTPS |

**不要**开 3000、7860、3306、6379 这些端口——网站走 nginx 转发，端口不外露。

不知道自己的 IP：百度搜「IP」，第一个结果就是；或者临时把 22 设成 0.0.0.0/0，部署完再收紧。

---

## 4. 买 OSS + 建两个桶（10 分钟）

**网址：https://oss.console.aliyun.com**

点「创建 Bucket」，填：

| 选项 | 公共读桶（图床） | 私有桶（备份） |
|---|---|---|
| 桶名 | novai-assets-加你的后缀 | novai-backup-加你的后缀 |
| 地域 | **中国香港** | **中国香港** |
| 读写权限 | **公共读** | **私有** |
| 版本控制 | 开启（防误删） | 开启 |
| 其他 | 默认 | 默认 |

说明：
- 桶名只能小写字母、数字、中划线，**全球唯一**，被占用就换个后缀。
- 公共读 = 拿到图片链接的人都能看（这是让 AI 能读取素材的前提）；文件名是 32 位随机串，别人猜不到、也遍历不了。
- 私有备份桶只给程序用，外网拿不到。

**记下两个桶名。**

## 5. 开一个「只能管 OSS」的小号（10 分钟）

**网址：https://ram.console.aliyun.com**

1. 左侧「用户」→ 「创建用户」。
2. 登录名称填 **novai-deploy**；访问方式**只勾「OpenAPI 调用访问」**，不要勾控制台访问。
3. 创建完成后，点进这个用户 → 「创建 AccessKey」→ 复制 **AccessKey ID** 和 **AccessKey Secret**（Secret 只显示一次，存到密码管理器或先贴到本地记事本）。
4. 同一个页面 → 「权限管理」→ 「新增授权」→ 搜索 **AliyunOSSFullAccess** → 选中 → 确定。

这个账号只能读写 OSS，动不了服务器、动不了别的产品；部署完你随时可以在控制台禁用。

**把这组 ID + Secret 发我（单独发，别发群、别截图）。**

## 6. 买域名（30 分钟 + 实名审核 1–2 天）

**网址：https://wanwang.aliyun.com**（域名注册）

1. 搜一个你喜欢的 **.com**，加入清单，结算，买 1 年。
2. 结算时要求填「信息模板」：姓名 + 身份证号 + 手机号，提交**域名实名**。
3. 实名审核 1–2 个工作日，通过前域名不能解析——**所以这一步尽早做，别等到最后。**

注意：
- 香港服务器**不需要 ICP 备案**，买 .com 最省事。
- 别买 .cn 以外的奇怪后缀，也不要用别人送的域名（实名不是你就控制不了）。

## 7. 域名解析到服务器（5 分钟）

**网址：https://dns.console.aliyun.com**

域名列表 → 找到你的域名 → 「解析设置」→ 「添加记录」：

| 记录类型 | 主机记录 | 记录值 | TTL |
|---|---|---|---|
| A | @ | 你的 ECS 公网 IP | 10 分钟 |
| A | www | 你的 ECS 公网 IP | 10 分钟 |

保存后等 10 分钟生效。团队会验证；你也可以在电脑上打开命令行输 ping 你的域名，能看到 IP 就成了。

## 8. 把 4 样东西发给团队（2 分钟）

2. **两个 OSS 桶名**（公共读图床 / 私有备份）+ 地域（香港）
3. **RAM 的 AccessKey ID + Secret**（第 5 步）
4. **域名**

安全要求：
- 用私聊或密码管理器发，**不要发群、不要截图**。
- 部署完成后，你可以立刻改服务器密码、在 RAM 里禁用这个 AccessKey，都不影响网站运行（团队要排障时再临时开）。
- **永远不要给主账号密码。**

可选：钉钉群机器人 Webhook（见第 12 步），用于接收告警。

## 9. 团队部署（你等，约 1 天）

团队会做（不需要你参与）：

- 装 Ubuntu 环境、Python 3.11、nginx、开机自启。
- 代码放 **/opt/novai**，数据目录 **/opt/novai/cloud-data**（全新的空目录，不碰你本地任何数据，试用期不同步）。
- nginx 反向代理 + 免费 HTTPS 证书（自动续期）。
- 接 OSS：上传素材落 OSS、生成结果立刻转存 OSS、素材库和 AI 引用都用 OSS 地址。
- 每日备份到私有桶；磁盘/余额/报错告警。
- 给你管理员初始账号和网址。

## 10. 你验收（半天）

用**手机 4G**（别用公司 Wi-Fi，避免误判），逐条过：

1. 打开 **https://你的域名**，地址栏有小锁，没有「不安全」提示。
2. 用管理员账号登录，生成一张图。
3. 刷新页面，图还在。
4. 复制图片地址，应该长这样：**https://novai-assets-xxxx.oss-cn-hongkong.aliyuncs.com/...**（不是服务器 IP 开头的路径）。
5. 换个浏览器注册一个普通账号（用邀请码），确认看不到管理员的画布和素材。
6. 让我重启一次服务器，网站 1 分钟内自动恢复。

全部通过 = 服务器部分验收完成。

## 14. 常见坑（照着避）

1. **没实名**：买不了 ECS、域名解析被锁。先做实名。
2. **域名实名 1–2 天**：别拖到最后，先买先审。
3. **香港 4 核 8G 没货**：先买 2 核 4G，后面可升配。
4. **带宽别选固定**：按使用流量便宜得多，图片走 OSS 后 ECS 流量很小。
5. **安全组别开 3000**：网站只走 80/443。
6. **公共读图床**：拿到链接的人都能看图；路径随机、不能遍历，但敏感图别传。
7. **主账号 AccessKey 不能外发**：只给 OSS 权限的小号。
8. **OSS 桶名全球唯一**：被占就换后缀，不用纠结。
9. **别用大陆 CDN 加速 OSS**：要备案，香港不需要。
10. **密码/密钥单独发**：部署完可改可停。
