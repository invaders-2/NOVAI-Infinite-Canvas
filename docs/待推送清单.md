**行为语义**
- 助手忙碌（`a.busy`）时输入框按 Enter：当前文本（含 `@{节点id}` / `@ref{}` / `@app{}` / `@skill{}` 记号）+ 引用快照（技能名、pinned、当时选中节点、refs、本轮联网开关）入队，并清空草稿 / 胶囊 / 技能 / 联网；toast「已加入队列（第 N 条）· 助手当前任务结束后自动发送」。
- 队列上限 5：第 6 条只 toast「队列最多 5 条，等前面的发完再加」，不清空输入、不丢内容。
- 队列为空且不忙时，Enter / 发送按钮行为与改动前完全一致。
- 忙碌 placeholder：全屏「助手执行中 · 按 Enter 加入队列」，窄面板「Enter 加入队列」。
- 编辑：从队列取出该条，把原始文本 + 引用胶囊 / 技能 / 联网还原到输入区，聚焦输入框，toast「已放回输入框，改完再发」。
- 立即发送（空闲）：直接从队列取出发送，行为与改动前一致。
- 立即发送（忙碌，队列里只有这一条优先）：先调用现有 `stopTask()` 停当前任务，并把这条记为 `pendingUrgent`，等 `busy` 转 false 后最先发，toast「已停止当前任务，马上发送这条」。
- 立即发送（忙碌，已经有一条 `pendingUrgent` 在等）：新点的这条标 `urgent:true` 插到队首（排在 pendingUrgent 之后、其余队列项之前），不覆盖前一条，toast「已排到优先队首，当前任务结束后马上发这条」；两条按点击顺序先后发出，一条不丢。
- 自动发送：只认 `busy` 由 true→false 这一下，260ms 后取队首（优先 urgent），先从队列移除再发，避免重复；发送用快照里的上下文，发完不清空用户当前正在编辑的新草稿。
- 切换对话 / 新建对话（含有无线程两种入口、账号切换）清空队列，避免发到别的线程。
