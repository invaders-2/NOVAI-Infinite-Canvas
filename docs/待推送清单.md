## ✅ 2026-11-13 · 2.0.07 · 节点自定义大小不被生成结果缩回默认尺寸

**状态**：随 v2.0.07 一起提交、push。改动：`novai-canvas-ui/src/canvas/canvas-next/{mediaFit.ts, engine.ts, store.ts}`、新增 e2e `tests/test_canvas_keep_size.cjs`；验收记录见 `_verification-keep-size/`。

**问题**：用户把节点拖大（例如 800×450）后，点生成 / 结果写回 / 换比例，过一会儿节点就被缩回 360×640 的默认最大盒（图片变 360 宽、视频同理），自定义尺寸保不住。

**根因**：结果写回、生成中占位、换比例都套 `fitMediaBox(…, MEDIA_FIT_MAX=360×640)`；它按当前宽度起算再把宽高收进最大盒，用户拖大的节点每次都被压回来。

**改动**
- `refitNodeBox` 升级：节点还在默认最大盒以内 → 和以前一样按宽度等比摆正；**已被用户拖到超过默认盒** → 同比例原样保留，换方向按「面积不变」换算（800×450 → 450×800），不再缩回 360 宽。
- 生成中占位、结果写回、换版本 / 换新结果节点、空节点换比例统一走 `refitNodeBox`；新建节点仍用原默认盒（不会凭空变大）。

**验收**

**边界**：默认尺寸以内的节点行为不变；超过默认盒的节点按面积保持块头，极端长条仍可能很扁（比例本身如此）。
