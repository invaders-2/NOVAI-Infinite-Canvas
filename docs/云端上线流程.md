## 一、目标形态

```
[桌面客户端] --HTTPS--> [云端 FastAPI] ──> APImart
                              ├──> OSS 香港（公共读图床）
                              └──> cloud-data/（试用期独立数据目录）
```

- 客户端只是入口：登录、画布、编辑器全在云端跑；本地不存任何上游 key，不发起模型调用。
- 试用期客户端是**薄壳**：内嵌云端地址 + 登录态，不打包本地抠图 / 超分 / ComfyUI，避免双后端打架；这些能力留在现有桌面版，二期再合。
- 云端持有：账号、邀请码、画布、素材、生成任务、APImart key、OSS key。
- 客户端持有：登录 token（存系统钥匙串）、界面缓存。
- **试用期不做任何本地↔云端同步**；服务端数据目录单独新建（`cloud-data/`），客户端 profile 也单独建（`~/NOVAI-cloud/`），互不覆盖。

## 二、五步流程

顺序不能倒：1 → 2 必须先做；3、4 可并行；5 收尾。

### 步骤 1 · 接上邀请制登录 + 6 位邀请码（2–3 天）

- `main.py` 加三行接入：`set_data_dir(DATA_DIR)` → `install(app)` → `bootstrap_admin()`。
- 邀请码生成器改为 **6 位数字随机**，写库前查重；默认**一次一码、7 天有效**，后台可调次数和有效期。
- 6 位数只有 100 万种，注册接口必须限流（每 IP 每小时 N 次 + 全局每分钟上限），否则能被枚举。
- 新写登录/注册页：用户名 + 密码 + 邀请码；登录失败统一提示。
- 管理员后台（最小集）：生成/停用邀请码、使用记录、账号列表、停用账号。
- 客户端首屏改成登录页，登录成功进云端画布。
- 关掉旧的 `NOVAI_LAN_AUTH` 局域网 token 门禁，只留一套鉴权。
- 验收：无码注册失败；6 位码可生成、可用、可停用；枚举式注册被 429 挡住。

### 步骤 2 · 用户数据分开 + 独立试用目录（1–2 周，最大工作量）

- 服务端启动固定用 `NOVAI_DATA_DIR=<部署目录>/cloud-data`，与本地 `data/` 完全隔离；**试用期不写同步逻辑**。
- 画布：创建写 `owner=user_id`；列表/回收站/最近只查自己的；读写前校验归属，别人的 ID 一律 404。
- 素材 / 历史 / 任务 / 对话：按用户分目录或加 user_id；对话接口改从会话取用户，不再信前端 `X-User-Id`。
- 客户端 profile 独立（`~/NOVAI-cloud/`），不与本地安装的 NOVAI 共用数据。
- 本轮不做共享 / 协作 / 公开链接，先"各看各的"。
- 验收：两个账号互查（画布、素材、历史、任务、直链）全部不可见或 404；本地数据一条没动。

### 步骤 3 · API 收口到 APImart（3–5 天）

- 模型调用固定走服务端 key；客户端 / 前端设置页对邀请用户隐藏（不能换供应商、填 key、改 base_url）。
- 模型清单后端下发，前端只读。
- 不做积分，但必须有防刷：每用户每分钟请求上限 + 并发上限、每日用量日志、后台一键停用账号/吊销邀请码、APImart 余额低于阈值告警。
- 失败请求明确报错；视频类长任务统一超时与轮询策略。
- 验收：普通用户看不到任何 API 配置；超频被拒；后台能按用户/按天看用量。

### 步骤 4 · 阿里云香港 + OSS 图床 + 资产库打通（3–5 天，可与 3 并行）

- ECS（香港）：Python 环境、nginx 反向代理、HTTPS、开机自启。
- OSS（香港）：桶**公共读**，文件名用 32 位随机串（不可遍历）；不开防盗链（APImart 要抓图）。
- **资产库直连 OSS**：上传立即落 OSS；生成的图片/视频**立刻从上游下载转存 OSS**（上游链接会过期）；素材注册表存 OSS URL + 缩略图地址；素材库页面直接读 OSS 链接。
- **AI 读取与应用**：Agent 的 @ 引用、APImart 参考图一律用 OSS 公网 URL；资产接口返回名称、标签、OSS URL，供后续 Agent 检索和复用。
- 删除/回收站要同时处理 OSS 对象；配生命周期清理孤儿文件；每日备份数据库 + 元数据到 OSS。
- 服务端关掉本地抠图 / 高清放大（CPU 杀手），能力留在桌面版。
- 验收：4G 网络打开客户端能登录能出图；图片 URL 全是 OSS；素材库刷新后资产还在；换账号资产不串。

### 步骤 5 · 上线验收与运维（2–3 天）

- 冒烟：客户端安装 → 登录 → 生图 → 生视频 → 对话 → 上传 → 刷新还在 → 换账号互不可见 → 资产库能看到。
- 监控：CPU / 带宽 / 磁盘 / APImart 余额，异常推送到钉钉或邮件。
- 备份恢复演练一次；回滚预案（发版前备份，出事十分钟退回）。
- 先发一小批邀请码给朋友试一周，这个阶段不公开推广。

## 四、四个硬约束

1. **香港服务器不能 ICP 备案**。邀请制小范围可用；公开推广或收费就必须回大陆主体（公司 + ICP 备案 + 算法/大模型登记，2–6 个月）。这决定产品能走多远。
2. **不做积分 = 花的是你的 APImart 余额**。必须限速、邀请码限次限期、可停用、余额告警；否则一次泄漏就能烧穿。
3. **服务器跑不了本地模型**（抠图 / 超分吃 CPU）。云端先关，桌面版保留。
4. **公共读图床意味着拿到链接的人都能看**。路径随机不可遍历，但不要往云端传敏感素材；真要管控就改成签名 URL，但 APImart 抓图会失效。
