## 0. 现有可复用的东西

| 能力 | 位置 | 社区里怎么用 |
|---|---|---|
| 局域网身份（account_id / 昵称 / 头像 / 好友码） | `server/routes/lan_account.py` | 作者身份，不新建账号体系 |

## 1. 架构：每台 NOVAI 都是一个社区节点（P2P，无中心服务）

```
 [我的 NOVAI]  ── UDP 47823 发现 ──▶  [同事 A 的 NOVAI]   [同事 B 的 NOVAI]
     │  GET /api/community/public/items（并发，1.5s 超时）        │
     ├──────────────────────────────────────────────────────────┘
     ▼
 作品流 = 我自己发布的 + 所有在线节点发布的 + 本地缓存（作者离线时置灰）
```

- **数据落盘**（全部原子写，沿用 lan_account 的写法）：
  - `<DATA_DIR>/community/items.json`：我发布的作品元数据 + 统计
  - `<DATA_DIR>/community/packages/<item_id>/`：发布包（`package.json` + `cover.webp` + 媒体副本）
  - `<DATA_DIR>/community/cache/peers.json` + `cache/covers/`：别人作品的元数据与封面缓存（作者离线时仍能浏览）
  - `<DATA_DIR>/community/me.json`：我的收藏、我点过赞的、我克隆过的、屏蔽的作者、已举报
- **统计归作者节点所有**：点赞数 / 克隆数 / 浏览数记在作者机器上，别人通过公开接口上报事件，按 account_id 去重。
- **传输层抽象**：后端写成 `CommunityTransport` 接口，这一期只实现 `LanTransport`；以后上云端（阿里云香港方案）只需加 `CloudTransport`，前端和接口形状不变。

## 2. 作品与发布包

```jsonc
// items.json 中的一项
{
  "id": "483920-k7f2q9",            // <作者账号码>-<随机>
  "kind": "canvas",                 // canvas | skill | prompt
  "title": "胶片暗房服装大片工作流",
  "desc": "参考图 + 白底图 → 4 张大片",
  "tags": ["服装", "大片"],
  "category": "电商",
  "cover": "cover.webp",
  "author": { "account_id": "...", "nickname": "Weiping", "avatar": "..." },
  "version": 3, "created_at": 0, "updated_at": 0,
  "allow_clone": true,
  "meta": { "nodes": 12, "models": ["auto"], "media": 8, "size_bytes": 0 },
  "stats": { "likes": 0, "clones": 0, "views": 0, "reports": 0 },
  "status": "published"             // published | unlisted（下架）
}
```

发布包内容按类型：

| 类型 | package.json 里放什么 | 发布前的清洗 |
|---|---|---|
| 画布 | `canvas_snapshot()` 的节点 / 连线 / 视图 | 去本机绝对路径；去 API key / provider 配置；模型名不写死（沿用"auto"规则）；可选"包含生成结果媒体"（默认开，单包上限 200MB） |
| 技能 | 技能定义 JSON（含说明正文） | 去 env / key / 本机路径；保留作者署名 |
| 提示词 | `{name, category, positive, negative}` | 无 |

封面：画布默认取最后生成的图片节点，可在发布弹窗里换；技能 / 提示词用图标 + 文字卡。

## 3. 接口

本机（前端用）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/community/feed?kind=&q=&sort=latest\|hot\|clones&category=` | 聚合作品流（本机 + 在线节点 + 缓存），含 `online` 标记 |
| GET | `/api/community/items/{id}` | 详情（远端作品经本机代理拉取，顺带 +1 浏览） |
| POST | `/api/community/publish` | `{kind, source_id, title, desc, tags, category, cover, allow_clone, include_media}` |
| PATCH | `/api/community/mine/{id}` | 编辑 / 重新发布（version+1） |
| POST | `/api/community/mine/{id}/unlist` | 下架（可恢复） |
| GET | `/api/community/mine` | 我的发布（含统计） |
| POST | `/api/community/items/{id}/clone` | 克隆 → `{kind, target_id, copied, failed}` |
| POST | `/api/community/items/{id}/like` / `favorite` / `report` | 点赞 / 收藏 / 举报（`{reason}`） |
| GET | `/api/community/favorites` / `clones` | 我的收藏 / 我克隆的 |

公开（给局域网其他节点调用，只读 + 事件上报）：

| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/community/public/items` | 本机已发布作品列表 |
| GET | `/api/community/public/items/{id}` | 详情（含只读预览所需的快照） |
| GET | `/api/community/public/items/{id}/package` | 发布包（`allow_clone=false` 时 403） |
| GET | `/api/community/public/media/{id}/{file}` | 发布包内媒体 |
| POST | `/api/community/public/items/{id}/event` | `{type: like\|unlike\|clone\|view\|report, account_id}` |

## 4. 克隆流程

1. 本机 `GET 作者/package` → 校验 schema、JSON ≤ 20MB；
2. **画布**：`localize_media_urls()` 把媒体拉到本机 `/assets/uploads/`，失败的标红占位 → 新建画布「原标题（克隆）」，写 `source: {item_id, version, author}`；
3. **技能**：新 id（`原id-c<短码>`）→ `import_skill()`；**默认停用**，克隆完成弹提示「来自 XXX 的技能，确认后启用」（防提示词注入 / 乱调工具）；
4. **提示词**：写进提示词库的「社区」分组；
5. 向作者节点上报 `clone` 事件；在「我克隆的」里留记录。作者离线：若本机缓存里有完整包（打开过详情就会缓存）仍可克隆，否则按钮置灰「作者离线」。

- **画布发布入口 = 画布右上角「分享」按钮**（`novai-canvas-ui/src/canvas/canvas-next/ui/ShareSheet.tsx` 的 `ShareMenuBody`）：在「分享链接」「打开分享链接」下面加第三项「发布到社区」（图标 `users`，说明「局域网里的人能在社区看到，并克隆这张画布」），点击打开发布弹窗。
  - 已发布过：这一项变成「已发布到社区 · v3」；画布有新改动时说明改为「画布有新改动，可以更新到社区」并带「更新」按钮；点进去是管理子面板（封面 / 版本 / 点赞克隆浏览数、改动提示、编辑信息、在社区查看、从社区下架、更新到社区）。
  - 菜单状态读 `GET /api/community/mine?source_id=<canvasId>`；「有新改动」= 画布 `updated_at` 晚于发布包的 `updated_at`。
- **发布弹窗**：填标题 / 简介 / 分类 / 标签 / 封面，开关「允许克隆」「包含生成结果」。技能在技能管理、提示词在提示词库各有「发布到社区」入口；社区页的「发布作品」按钮先选类型和来源，再进同一个弹窗。
- **「我的」页改为个人主页**（重写 `web/src/pages/me/MePage.vue`）：顶部通栏背景图（可自定义：上传图片 / 从素材库选择 / 调整位置 / 恢复默认，存 `<DATA_DIR>/community/profile.json` 的 `cover` + 焦点位置，图片落本机上传目录）；大头像压在背景下沿；右侧「分享主页」「编辑资料」；昵称 + 好友码；统计 作品 / 获赞 / 被克隆 / 浏览 / 好友（好友可点，弹出好友浮层：添加好友、在线状态、主页、消息含未读数、我的好友码复制，数据沿用 `/api/lan/friends`）；分隔后是 Tab「发布 / 点赞 / 收藏 / 克隆」，右侧 排序（最新）、全部类型、全部状态（已发布 / 已下架 / 被举报）、作品名搜索、「发布作品」；下面是作品卡网格（状态角标、举报数、右上「更多」= 编辑 / 下架 / 删除）。原来的资料 / 账户内容并入「编辑资料」弹窗。别人在社区点作者头像看到的是同一个主页（只读，无编辑按钮），背景图随作品元数据一起下发。
- 设置 → 通用：「在局域网社区中可见」总开关（关掉后公开接口一律 404）。
- 全部沿用 Glass v2：无描边、磨砂底、线性图标、操作按钮右对齐、输入框无聚焦光圈。

## 6. 安全与边界

- 公开接口只读发布包，绝不暴露画布库 / 素材库 / 配置；路径参数白名单校验，防目录穿越。
- 限流：每 IP 每分钟 120 次读、30 次事件；事件按 account_id 去重。
- 遵守已有 `NOVAI_LAN_AUTH` 门禁；局域网可见开关默认 **关**，第一次发布时引导打开。
- 举报：本机立即隐藏该作品；作者在「我的发布」看到举报数和原因，可下架；可「屏蔽此作者」。
- 局域网版的天然限制：只覆盖同网段、作者得在线；克隆过的作品与作者断开，不自动同步更新（详情页显示「原作已更新到 v4」作为后续可选项）。
