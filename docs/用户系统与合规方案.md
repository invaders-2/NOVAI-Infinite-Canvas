# NOVAI 用户系统与合规落地方案

> 版本：2026-10　适用：NOVAI（无限画布 · AI 创作工具）部署到公网前后
> 说明：合规口径以属地网信办 / 通信管理局最新要求为准，本文用于排期与决策，不替代法律意见。

---

## 0. 一句话结论

用户系统可以"一步到位"做出来（邀请码 + 注册登录 + 体验额度 + 管理后台，约 2 周），但有一个硬卡点必须先说清楚：

**公开注册的用户不能用 APIMart 的境外模型（GPT / Claude / Gemini / Nano Banana / Flux）。**

原因有两条，都是硬约束：

1. **上游模型未备案**：国内面向公众提供生成式 AI 服务，走"大模型登记"的前提是调用**已备案**的模型。GPT / Claude / Gemini 没有中国备案，登记过不了。
2. **数据出境**：APIMart 的接口在境外（`api.apib.ai` 解析到阿里云香港），公开用户的数据发到那里，就构成"向境外提供个人信息"，需要按《个人信息保护法》第 38 条走安全评估 / 标准合同 / 认证，成本和周期都很高，且 2026 年已有中转站因数据出境被追责的案例。

**可行形态：公开用户走境内已备案模型（豆包 / 即梦 / 通义 / DeepSeek），团队内部走 APIMart 全模型。** 模型按角色强制路由，后端做，不靠前端。

## 1. 现状与监管背景

现状（已核对代码）：

- `main.py` 是单用户后端，**没有任何登录鉴权**；
- apimart key 存在服务器 `data/api_providers.json` / `API/.env`，所有人共用一份余额；
- 素材、历史、任务都是全局的，没有按用户隔离；
- 一旦公网可访问，任何人扫到端口就能消耗你的余额、查看素材。

监管框架（2026 年现行）：

| 轨道 | 管什么 | 周期 | 难度 |
|---|---|---|---|
| 算法备案 | 所有对外 AI 服务，算法机制透明 | 2–4 个月 | ★★★ |
| 大模型登记 | 调用**已备案**模型做应用/功能 | 1–3 个月 | ★★★★ |
| 大模型备案 | 自研 / 微调模型对外服务 | 6–8 个月 | ★★★★★ |

- 三者不是二选一：算法备案是基础项，登记/备案按"你是调 API 还是自研"选。
- 2026 年 4 月起"清朗·整治 AI 应用乱象"专项行动，**未履行备案登记是重点整治项**，已处置违规 AI 产品 1.4 万余款。
- 对 API 输出做内容过滤、重组、审核等二次处理，可能被认定为"实质性修改"，从而从"登记"升级为"备案"（周期 6–8 个月）。这一点在设计审核链路时要提前和属地网信办确认口径。

## 2. 产品架构建议

### 2.1 角色

| 角色 | 来源 | 模型范围 | 额度 |
|---|---|---|---|
| admin | 你（首个账号） | 全部 | 不限 |
| team | 团队邀请码注册 | APIMart 全部（含境外） | 高额度，可调 |
| user | 公开注册（手机号） | 仅境内已备案模型 | 体验额度 + 每日免费额度 |

### 2.2 模型路由（后端强制）

```
team  → APIMart（api.apib.ai）全模型
user  → 火山引擎豆包/即梦、阿里云百炼通义、DeepSeek 等境内 API
admin → 两边都能用
```

后端在发起模型调用前按 `user.role` 取 provider 白名单，拒绝越权；前端只展示当前角色可用的模型。

### 2.3 数据隔离

```
data/users.db                # SQLite
data/assets/<user_id>/<date>/...
data/logs/usage-YYYY-MM.jsonl
```

素材、历史、任务全部带 `user_id`，接口层校验归属；管理后台可查看全部，普通用户只能看自己。

## 3. 用户系统 MVP 功能清单

### 3.1 账号

- 手机号 + 验证码注册，设置密码；邀请码选填。
- 登录：手机号/邮箱 + 密码，HttpOnly Secure Cookie 会话。
- 找回密码：手机验证码重置。
- 注销账号：软删除 + 30 天后清理素材（隐私政策写明）。

### 3.2 邀请码

- 团队码：绑定 `role=team`，可设使用次数/有效期，用完即止。
- 体验码：注册后额外赠送额度（用于活动/朋友）。
- 管理后台可生成、停用、查看使用记录。

### 3.3 体验额度（建议值，可调）

| 项目 | 新用户体验 | 每日免费 | 团队 |
|---|---|---|---|
| 图片 | 20 张 | 3 张 | 500 张/月 |
| 视频 | 2 段 | 0 | 30 段/月 |
| 对话 | 50 次 | 10 次 | 不限（限并发） |

- 额度按"模型计费单位"折算，不用"次数"拍脑袋。
- 失败请求自动退还额度。
- 体验额度不可转让、不可叠加多账号刷取：手机号唯一 + 设备指纹 + 注册限流。

### 3.4 管理后台

- 用户列表：搜索、封禁、改角色、改额度、重置密码。
- 邀请码管理。
- 用量统计：按日 / 按模型 / 按用户；费用估算。
- 上游余额告警（APIMart / 火山引擎余额低于阈值时邮件/钉钉通知）。
- 审核队列：待人工复审的命中记录。
- 操作审计日志。

### 3.5 安全

- 密码 bcrypt / argon2 哈希；登录失败 5 次锁定 15 分钟。
- 注册图形验证码 + IP/设备限流。
- CSRF token；所有管理接口二次校验角色。
- 强制 HTTPS；数据库每日备份。

|---|---|---|---|---|---|
| 1 | 域名实名 + ICP 备案 | 1–3 周 | 免费 | **大陆服务器** + 域名实名 | 香港服务器不能备案；备案号放页脚 |

## 6. 内容审核怎么做

**双向审核：输入 + 输出。**

- 输入文本：本地敏感词库（涉政/涉黄/暴恐/违禁）→ 云内容安全 API 复核（阿里云内容安全 / 腾讯云天御 / 网易易盾）。
- 输入图片：NSFW、涉政、涉黄、暴恐检测。
- 输出图片/视频：生成结果再过一遍检测；视频抽首帧 + 关键帧。
- 命中处置：拦截并提示、记录 `moderation_logs`、累犯自动封禁、进入人工复审队列。
- 举报入口：每个作品可举报，后台处理留痕。
- 日志留存：不少于 6 个月（《网络安全法》要求）。

**建议链路：** 本地词库快速拦截（零成本）→ 云 API 兜底（按量）→ 人工复审（高风险样本）→ 封禁/申诉。

## 7. AI 生成内容标识怎么做

依据《人工智能生成合成内容标识办法》（2025-09-01 施行）及配套强制性国标：

**显式标识（用户能看见）**

- 图片：在画面适当位置加"AI 生成"角标（建议右下角，半透明、不遮挡主体）。
- 视频：起始画面 + 播放周边加提示，可在末尾/中间追加。
- 对话文本：开头或结尾加提示，或界面显著位置提示。

**隐式标识（文件元数据）**

- 图片：PNG/JPEG 写入 XMP/EXIF：生成合成属性、服务提供者名称或编码、内容编号、生成时间。
- 视频：容器元数据写入同样的要素。
- 导出、下载、复制都必须带标识；用户协议写明标识方式。

**例外**：用户可申请无显式标识的版本，但需在协议中明确用户标识义务和使用责任，并留存提供对象信息等日志不少于 6 个月。只对可信用户开放，不对公众默认提供。

## 8. 分阶段路线

### Phase 1（约 2 周，现在就能做）

- 用户系统：注册/登录/会话/找回密码
- 邀请码（团队码 + 体验码）
- 体验额度 + 每日免费额度 + 配额扣减/退还
- 素材按用户隔离
- 使用日志 + 管理后台
- 对外仍是邀请制，**不开放公开注册**

### Phase 2（1–3 个月，合规并行）

- 完成 ICP 备案 + 公安备案
- 接入内容审核 + AI 标识 + 手机号实名
- 公开注册灰度：用户只能用境内已备案模型
- 算法备案 + 大模型登记申报

### Phase 3（收费前）

- 公司主体 + ICP 许可证
- 支付、账单、发票、退款规则
- 会员/套餐体系
- 等保二级

---

## 9. 需要拍板的 3 件事

1. **公开注册的用户，是否接受只能用国产已备案模型**（豆包 / 即梦 / 通义 / DeepSeek）？境外模型只给团队？
2. **是否收费**？免费公开（ICP 备案即可）还是会员收费（要 ICP 许可证 + 公司）？
3. **有没有公司主体**？没有的话，公开注册和收费都要先注册公司。

---

## 10. 确认后我做什么

派工做 Phase 1：数据库 + 鉴权 + 邀请码 + 配额 + 管理后台 + 素材隔离；内容审核和 AI 标识先留接口，Phase 2 接入。同时你并行去办域名实名和 ICP 备案（这一步最耗时，越早越好）。
