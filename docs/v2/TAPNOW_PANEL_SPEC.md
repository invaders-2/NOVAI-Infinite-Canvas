# TapNow 画布助手面板 · 实测规格（REA，2026-10-25）

来源：本机 TapNow 0.4.149 Electron，CDP 连接 `127.0.0.1:9225`（`--remote-debugging-port`），
打开 `tapnow://app/canvas/8ecd80f5-…` 后点击右下角气泡展开助手面板，读取 `getBoundingClientRect` 与 `getComputedStyle`。
视口：1600×1000 CSS px（DPR 2），暗色主题。

## 与当前实现的差异（待改）
1. 面板是**贴边全高抽屉**（宽 440、仅左侧 16px 圆角、#141414），不是浮在画布上的圆角卡片。
2. 顶部栏 60px + 三枚 36px 图标（新对话＋ / 全屏 / 更多）+ 左侧 40px 侧边栏开关 + 86px 新建对话。
3. 空状态：Hi 24px/300 灰 + 标题 28px/400 + **建议卡**（16px 圆角、#1a1a1a、1px 白 5% 边框、内边距 16/36/16/12、标题 14/500、描述 12/400 45% 白）+ 换一批。
4. 输入区：424 宽、16px 圆角、#1a1a1a、0.5px 白 10% 边框、30% 透明阴影、14px 输入、底部一排 32px 图标。
5. 上下文占用、Auto、语音、发送都在**输入区内**，不在顶部栏。
