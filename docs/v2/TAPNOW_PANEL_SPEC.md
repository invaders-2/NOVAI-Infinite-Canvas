## 与当前实现的差异（待改）
1. 面板是**贴边全高抽屉**（宽 440、仅左侧 16px 圆角、#141414），不是浮在画布上的圆角卡片。
2. 顶部栏 60px + 三枚 36px 图标（新对话＋ / 全屏 / 更多）+ 左侧 40px 侧边栏开关 + 86px 新建对话。
3. 空状态：Hi 24px/300 灰 + 标题 28px/400 + **建议卡**（16px 圆角、#1a1a1a、1px 白 5% 边框、内边距 16/36/16/12、标题 14/500、描述 12/400 45% 白）+ 换一批。
4. 输入区：424 宽、16px 圆角、#1a1a1a、0.5px 白 10% 边框、30% 透明阴影、14px 输入、底部一排 32px 图标。
5. 上下文占用、Auto、语音、发送都在**输入区内**，不在顶部栏。

## 补充实测（2026-10-26 · 历史对话与菜单）

- **执行摘要**：可展开按钮显示「看了 2 张图，读了 2 个文档，完成了 9 个操作 · 4m16s」；工具记录逐步保留，运行中与完成后的耗时分开。
- **结果操作**：助手正文后有节点引用 chips，可复制、好评、差评、分支对话；节点 chip 可回到对应画布内容。
- **空态**：两张项目建议卡 + 换一批，点击只填输入内容；线程下拉含新建和最近对话。
- **产物侧栏**：顶栏左侧按钮在助手左边展开「文件」区域，与对话并列；没有产物时显示「暂无输出」。

## 当前版本逐项实测（2026-10-27 · v2.21.33）

本轮使用用户授权的 Chrome 登录态，在现有画布完成文本节点测试；未提交图片或视频生成，积分保持 1500。

### 输入区与菜单

- 底部左侧只有「＋、手动生成」，右侧为「上下文占用、模型、语音、发送」。
- ＋菜单共 5 项：从画布添加、上传附件、技能、头脑风暴、全部应用；上传附件和技能后有分隔。
- 技能菜单：搜索、技能名称列表、上传技能文件、上传技能文件夹、创建技能、管理技能。
- 全部应用：搜索、已安装应用、管理应用；没有已安装应用时显示「暂无已安装应用」。
- 更多菜单只有「用量统计、收起对话」；用量统计进入团队用量看板。
- 产物侧栏标题为「文件」，空态为「暂无输出」。
- 从画布添加会进入节点选择模式：顶部显示「从画布添加／点击节点以添加为引用／退出」，点击节点后输入区出现可移除的类型 chip。
- 上下文弹层显示「已用 token、占比」，有总量时追加「上下文总量」。

### 消息区与真实画布动作

- 用户气泡保留原文、复制和时间；助手回复包含自然语言、内联节点 chip、复制、好评、差评、分支对话和时间。
- 执行摘要可展开，包含「已思考 Ns」和具体操作；问题导航可跳转到任意一轮用户消息。
- 新建文本节点：「修改画布 1 次 · 1s」。
- 修改文本节点：「修改画布 1 次，查看画布 1 次 · 5s」。
- 删除节点：运行中为「正在编辑画布」，完成后为「编辑了画布」和明确结果。
- 整理节点：先显示「正在选择节点」，完成后为「修改画布 1 次，查看画布 1 次 · 6s」，附两个节点 chip。
- 连接节点：先显示「读取节点」，完成后为「修改画布 1 次，查看画布 1 次 · 5s」，真实形成 Text → Generate Image 连线。
- 不存在的节点：「查看画布 1 次 · 1s」并明确说明无法删除。
- 手动生成模式可先创建并配置生成节点但不提交付费生成。

## NOVAI 实现口径（2026-10-27）

- 同尺寸视觉复测：输入卡为 16px 圆角、深色 #1a1a1a、轻阴影；＋按钮 32px，回复操作按钮 24×24、图标 14px。
- 用户正文 13px / 1.65，灰色右对齐气泡，复制按钮在气泡下方；助手回复无气泡，默认只显示复制、好评、差评、分支四个纯图标，时间保留在无障碍树。
- 执行摘要保留左侧执行图标与右侧展开箭头，完成态不显示进度计数；思考和工具记录位于展开区域内。
- 节点 chip 通过 Markdown 末尾插槽内联在回复正文中，Text 使用文本图标；问题导航使用右侧编号轨道直接跳转。
- 撤销保留在执行明细，用量保留在上下文入口，产物统一在产物侧栏，避免占用回复正文。
- ＋主菜单为 252px 宽、36px 行高、13px 字体、16px 图标；子菜单为 288px 宽，最高 420px，按内容自适应高度，超出后滚动。
- `canvas-ui/src/assistant/` 保留原 Agent 宿主协议；摘要来自真实 `vision` 与工具事件，读、写、文档、生成和删除分别计数，不伪造操作。
- 节点 chips 经 `window.focusSmartNode()` 选中并居中；反馈经 `/api/agent/threads/feedback` 持久化，分支后的反馈相互独立。
- 技能列表和导入使用 `/api/skills`、`/api/skills/import`。
- 「管理应用」通过应用外壳 `navigate: store` 打开应用中心；目录、详情、安装和启动回填已在隔离数据中端到端验证。
- 「全部应用」只列 `/api/store/catalog` 中 `installed=true` 的条目，每次打开重新拉取安装态；支持搜索、空态和添加为输入区应用引用。
- 录屏实现保留在 `recording.ts` / `RecordingMenu.tsx` 中，但当前 TapNow 输入区没有该入口，因此默认不显示。需要时仍可复用 Electron `desktopCapturer` + `setDisplayMediaRequestHandler` + `MediaRecorder` 和 `/api/local-assets/upload`。
