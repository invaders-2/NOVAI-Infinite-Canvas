# 智能画布 · 图片节点工具条规格（对齐 liblib.tv，功能全量落地）

> 参考对象：liblib.tv 画布里「选中图片后浮出的图片工具条」（用户截图那一排）。
> 本文记录实测到的每一个功能、它的面板与参数，以及我们在 NOVAI 里的实现路径。
> 硬约束：**设计语言用我们自己的**（磨砂玻璃/无描边/线性图标/软底选中态）；**原有交互动效必须保留**。

## 二、NOVAI 实现路径（每项都要真能跑出结果）

| 功能 | 我们的实现 |
|------|-----------|
| 人像调节 / 情绪调节 | 复用 provider 图生图管线（/api/canvas-image-tasks + 参考图 + 指令），面板给强度档位，运行产出新图 |
| 全景 | 同上，指令按 equirectangular/720° 全景拼；结果可用我们已有全景查看器看 |
| 多角度 | 面板参数（视角预设 + 水平/俯仰/景别）拼成指令 → 图生图 |
| 打光 | 面板参数（主光源方位/亮度/轮廓光/透视）拼成指令 → 图生图 |
| 九宫格 | 已有斜杠模板库（SLASH_COMMANDS）✓ 已接 |
| 高清 | 已有本地 AI 放大（openHdUpscalePanel）✓ |
| 扩图 | 已有 outpaint 管线 ✓ |
| 重绘 | 已有遮罩 + 提示词重绘 ✓ |
| 擦除 | 新增：涂抹 → 以「移除该物体并补全背景」的指令走遮罩重绘管线 |
| 抠图 | 已有本地 RMBG 抠图 + 高质量抠图 ✓ |
| 裁剪 | 已有裁剪（比例预设）✓ |
| 元素编辑 | 新增：点选/框选/画笔选区 + 「编辑内容」输入 → 局部重绘管线 |
| 图层分离 | 新增：本地抠图得主体层（透明 PNG）+ 背景层（对主体区域做 inpaint 补全），「N 拆分」产出多个图片节点 |
| 宫格切分 | 已有切分/拼接；**要补 4×4 / 5×5 / 自定义行列** |
| 标注 | 新增：在图上画箭头/方框/文字，本地 canvas 烧进图片 |
| 旋转 | 新增：左转/右转 90°、水平/垂直翻转（本地即时） |

## 三、交互与设计硬约束

1. **保留原有交互动效**（这次被删掉的，必须接回来）：
   - 图片节点工具条默认是**图标态**；指针进入整条 bar（含内边距与按钮间隙）→ 所有标签一起**展开**（max-width 插值 + margin-left 5px + opacity/translateX/blur 过渡，走 --fluid-* 缓动）；
   - **高亮滑块** `.smart-node-menu-highlight` 跟随当前悬停的那个按钮移动，按钮自身不给底色（避免叠亮）；
   - 支持 `:has(:focus-visible)` 键盘路径与 `prefers-reduced-motion`；
   - 展开/收起由 `initSmartNodeMenuMotion` 那套逻辑驱动：**新工具条要接进同一套机制**，不要另起一套。
2. 设计语言：磨砂玻璃配方 + 无 border/描边（分组之间只留间距），选中态 = 半透明软底 + 文字提亮 + 字重变化；图标一律 lucide 线性；亮/暗主题都正常。
3. 工具条不得参与节点拖拽、不得跑出窗口（横向夹取 + 竖向必要时翻面）。
4. 菜单/面板沿用我们的浮层动画（淡入 + 轻微缩放/位移），不要做成生硬显示。

## 四、验收（每一条都要有可复现证据）

- 13 个入口全部存在，顺序与参考一致（九宫格 → 裁剪组 → 元素编辑 → 图层分离 → 宫格切分 → 标注/旋转/下载/预览）。
- 裁剪组 6 个子项逐个点开都有对应 UI，且选谁按钮文案变谁。
- 每个「运行」都要真的走通我们现有管线（Playwright 里拦截 /api/canvas-image-tasks 的请求体作为证据）。
- 本地功能（旋转/抠图/裁剪/宫格/标注）要产出真实文件/新节点。
- 动效：截图或录屏证明「图标态 → 悬停展开 + 滑块跟随」仍在（亮暗各一份）。
- 项目自带 node 测试以 `node tests/run-all.js` 全绿为准。

## 五、照片预览（双击图片）—— Boss 定的硬规则

**双击图片打开的那个预览里，只允许出现三样东西：预览 / 对比原图 / 调色。其它一律不许出现。**
- 现在编辑弹层顶部那条模式条（预览 / 裁剪 / 扩图 / 遮罩 / 画笔 / 缩放 / 宫格切分 / 调色）里的**裁剪 / 扩图 / 遮罩 / 画笔 / 缩放 / 宫格切分 必须从预览里拿掉**，页面上不再有这些入口；
- 这些编辑能力全部搬到节点工具条上、**直接在节点图上做**（in-canvas 覆盖层：裁剪框、涂抹、扩图框、宫格线、调色面板），不许再靠切换预览弹层的模式来实现；
- 「对比原图」保留（按住看原图），「调色」保留（进我们已有的调色面板）；
- 验收：双击任意图片 → 顶部只剩 预览 与 调色，右下角只有 对比原图；截图 + DOM 断言（模式条里不得存在其它模式按钮）。
