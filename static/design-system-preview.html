青柠仅用于：Send Button、AI 光束、AI 流光 / 能量轨迹、AI 工作时光效、极少数品牌动画。
禁止用于：普通按钮与 CTA、Menu、Context Menu、Tab、Selected、Hover、Focus、Dock / Window active、 Input focus、Card、Panel、Dialog、Tooltip、Notification、页面标题、大面积背景、普通状态点。
