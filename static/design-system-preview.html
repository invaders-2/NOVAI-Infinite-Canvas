Icon System · 统一线性图标

全部 Linear / Stroke 风格；stroke-linecap & stroke-linejoin 均为 round。规范：16px→1.4 / 18px→1.5 / 20px→1.6 / 24px→1.7 / 32px+→≤1.8；尺寸体系 12/14/16/18/20/24/32/48/64。颜色走 --icon-primary / secondary / tertiary / disabled，青柠底用 --icon-on-brand。禁止实心 / 粗黑 / 卡通 / 彩色与跨库混搭。

Buttons · hover 抬起 + sheen 镜面

primary = 系统主交互（Light 黑底白字 / Dark 白底黑字）；secondary / ghost / danger 玻璃中性体

Inputs · 嵌入材质的柔和输入区（无阴影 / 无边框 / 无 ring）

无 border / 无 outline / 无 focus ring / 无 inset 与外阴影。Normal → Hover → Focus 只靠 surface 明度差推进，Focus 时材质加深。

Icon Buttons · 0 visible border / 0 ring

状态只通过 surface 明度、brightness、micro scale 表达。图标被材质托住，没有被框在小框里。尺寸 28 / 32 / 40 / 48（图标 16 / 18 / 20 / 24）。

Material Tiers · 4 档低雾化真实材质差（明度 / 实度 / tint / 内部受光 / 厚度）

四档差异 = fill 实度（相对背景的明度差）+ material tint + 内部受光 + blur 厚度，不是"只有 blur 不同"。都能与纯色背景区分，但都不靠边框。

Accessibility Test · Reduce Transparency

底层能力保留，但不再是主要视觉开关。默认材质本身已经采用此前 Reduce Transparency = ON 的干净方向（低雾化、半实、清晰）；打开此项只是进一步去掉残余 haze。正式系统上位于 System Settings → Accessibility → Display。
