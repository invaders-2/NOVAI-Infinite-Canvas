NOVAI MCP 文档

让 Claude、Codex、WorkBuddy 等外部 Agent 通过 MCP 调用 NOVAI 的画布工具。

这是什么

NOVAI 提供一个 MCP Server（入口 novai_mcp_server.py），外部 Agent 通过 stdio 或 Streamable HTTP 连接它，就能列出画布、新建/更新/删除节点、触发生图。

方向是「外部 Agent → NOVAI」。反向的「NOVAI 调用外部 MCP 工具」在设置页的 MCP 区块配置，两者互不影响。

stdio 配置（推荐）

安全提示

该进程以你的系统用户权限在本机运行；它能做什么，取决于该用户在 NOVAI 里的权限。不要把带权限的 NOVAI 地址暴露给不可信客户端。

  • NOVAI_BASE_URL 建议只指向本机 127.0.0.1 或 localhost。
  • NOVAI_API_TOKEN 通过环境变量传入，不写进仓库文件。
  • HTTP 模式默认只监听 127.0.0.1；改成 0.0.0.0 前先确认网络边界。

故障排查

连不上 NOVAI

NOVAI 没启动或端口不对。先 curl http://127.0.0.1:<端口>/api/canvases 确认。

HTTP 401

需要登录态但没给或给错 NOVAI_API_TOKEN。

GET /mcp 405

HTTP 传输不支持服务端推送流，改用 POST。

-32601 / -32700

方法名不在 initialize / tools/list / tools/call / ping 内，或请求体不是合法 JSON。

画布 / 节点不存在

canvas_id / node_id 错误；先 list / get 取正确 id。

生图未配置模型

到「设置 → API 设置」里给生图平台配置模型。

两个方向的区别

MCP Server（本页）

外部 Agent → NOVAI。入口 novai_mcp_server.py，NOVAI 是被调用方。

MCP Client（设置页）

NOVAI → 外部工具。配置在 data/mcp_servers.json，需要 NOVAI_MCP_ENABLED=1，把外部工具并进画布助手。
