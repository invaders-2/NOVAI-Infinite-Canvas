# NOVAI Fashion Studio Skill v1.1.4

这是面向 **NOVAI 2.0 Canvas Assistant** 的原生画布运行 Skill。它不是 Claude Code Skill，也不是独立网页应用。

## 改了什么（对应你提的需求）

| # | 你的反馈 | 这一版的改法 |
|---|---|---|
| 1 | 生成的图里会出现文字、英文 | 新增「文字清零」强制模块：每张提示词必须有独立文字清零段；提示词里禁用会诱发文字的名词（品牌名、招牌、海报/标题/slogan、裸英文单词）；给出「别写 → 改成」替换表、风险分级与出字返修流程（定点返修，不整组重做） |
| 2 | 不需要七分身特写 | 景别池只保留全身 / 半身 / 近景 / 局部特写 / 远景，**明确写入"不做七分身"**及原因；用户坚持时说明代价并改写成半身，不写七分身 |
| 3 | 缺少镜头参数 | 新增「镜头参数体系」：焦段表（24/35/50/85/135/100 微距）、光圈表、机位高度表、距离与景深、三套标准配方（Editorial / E-commerce / Hybrid）、一行式写法与匹配禁忌；镜头表、表格字段、提示词结构、质量清单全部同步加了焦段/光圈/机位/距离 |
| 4a | 缺少前置需求访谈 | 新增「前置需求访谈（Creative Brief Interview）」模块：先复述再问、三轮九问、每题带选项和默认值、给跳过规则、固定格式的 Brief 回执（标已确认/默认/待定）以及"没确认不建节点不生成"的确认闸门 |
| 4b | 访谈时如果有参考图，别再问图里已经有的 | 新增「选项从哪来」规则：参考图能读出的（素材、人物、服装、场景、光线、景别/焦段）直接当预选项并标 `[参考图]`，不再问；每题末项固定为「其他（我自己填）」；Brief 回执按来源四标（已确认 / 参考图 / 默认 / 用户填） |
| 4d | 要装成 NOVAI 官方技能 | 作为 `runtime: canvas` 的内置技能包装进 `server/skills/builtin_packs/novai-fashion-studio/`：应用市场「技能」内以「官方」卡片出现，点添加即可用。
| 4e | 正文被压过，要按原版来 | 恢复完整版正文（2.16 万字符，全细节）；同时把后端单技能注入上限从 2 万提到 4 万，完整版不会再被截断。压缩版（1.23 万）留在 v1.1.3，需要短提示词时可用 |
| 4c | 用户会传模特、产品、参考图、穿搭；没传要先问 | 新增「第 0 步 · 素材盘点」：四类槽位（模特图 / 产品图 / 参考图 / 穿搭图）先看画布再问，一组问完；缺哪类就在回执与方案里标"不可锁"，不假装能还原。追加「7.5 拍摄方案模板」，Brief 确认后出可直接建节点的详细方案 |

顺带修的准确性问题：

- 工具名对齐 NOVAI 真实画布工具：`create_node` / `update_node` / `run_generation` / `generate_image` / `batch_generate` / `run_batch` / `check_task` / `use_asset`（原版写的 `view_image` 不存在）。
- 画幅只用工具枚举支持的比例：1:1 / 2:3 / 3:4 / 4:3 / 9:16 / 16:9，不再写 21:9 之类。
- 明确 `generate_image` 没有单独的负向提示词字段，禁止项要写进正向提示词的末尾一段。
- 机身/镜头型号不再写进提示词（容易被渲染成画面里的品牌文字），只写"全画幅质感"。

## 包含内容

- `SKILL.md`：可独立导入 NOVAI 的主 Skill，已内嵌访谈流程、参考图分析、PoseSpec、镜头参数体系、文字清零约束、画布执行协议、质量清单与确认闸门。
- `novai-pack.json`：NOVAI 内置技能包使用的元数据（`runtime: canvas`，版本 1.1.4）。
- `references/CAMERA_LENS.md`：镜头参数扩展库（焦段—景别矩阵、光圈矩阵、机位、距离、品类配方、光型、常见错误）。
- `references/NEGATIVE_LIBRARY.md`：文字清零库（标准句、替换表、风险分级、返修话术、失败案例）。
- `references/POSE_LIBRARY.md`：姿势文字库，已补"推荐镜头"一列，并与景别池保持一致（无七分身）。

## 安装方式

### 方式 A：导入主 Skill（推荐）

1. 解压 ZIP。
2. 在 NOVAI 中打开「设置 → 技能 / 应用市场」或技能管理入口。
3. 选择本地导入 Skill，导入 `SKILL.md`。
4. 启用 `NOVAI Fashion Studio`。
5. 新建测试画布，上传一张人物图 + 一张服装图（可选姿势参考图）。
6. 输入：「我想拍一组春季男装电商图。」
7. 检查它是否先提问（用途/数量/素材/锁定/禁止项），再发 Brief 回执并停下等你确认。

### 方式 B：官方内置 Pack（已按此方式安装）

把整个目录放入 `server/skills/builtin_packs/novai-fashion-studio/`（安装版在 `/Applications/NOVAI.app/Contents/Resources/backend/server/skills/builtin_packs/`）。后端每次 `load_skills()` 会扫描并复制到数据目录 `data/skills/novai-fashion-studio/`；官方技能默认不启用，在 应用市场 → 技能 里点「添加」后才可用。不要覆盖现有 `fashion-editorial` / `fashion-editorial-director` 包。

## 建议验收用例（v1.1.4）

1. **素材盘点**：什么都不传，只说"帮我拍组春天的模特图"，检查它是否先问模特/产品/参考图/穿搭四类素材，再谈创意；缺的类别是否在回执里标了"不可锁"。
2. **访谈闸门**：只说"帮我拍组模特图"，检查是否会提问、是否发回执、是否在未确认前拒绝建节点。
3. **参考图优先**：上传一张模特图 + 一张服装图后说"帮我拍组图"，检查它是否先报"我在画布上看到…"、是否照参考图报出光线/场景/镜头，而不是再问一遍素材和风格；每个问题末尾是否有「其他（我自己填）」。
4. **其他出口**：在任一处回答"其他：我要暖金色的黄昏光"，检查它是否复述确认并按这条改，而不是跳回固定选项。
5. **跳过访谈**：说"你直接出 4 张"，检查是否只发回执不提问，并给 3 行理解摘要。
6. **镜头参数**：要求 4 张时尚大片，检查每张是否有焦段、光圈、机位高度、距离、景深目标，且整组至少 2–3 个焦段。
7. **七分身**：检查镜头表里是否完全不存在七分身/膝上裁切；若你坚持要，检查它是否说明代价并改写成半身。
8. **文字清零**：检查每张提示词是否有独立文字清零段、是否还残留品牌名/招牌/海报/英文单词。
9. **出字返修**：指出"右下角背景板有英文字母"，检查是否定点改提示词并只重生成该张，而不是整组重做。
10. **参考图拆解**：上传姿势图，检查是否能分辨重心、身体朝向、手臂、腿部、头部、机位，并换算成镜头参数。
11. **服装锁定**：上传商品图要求换姿势，检查提示词是否明确禁止改变商品结构。
12. **E-commerce**：要求正面、侧面、背面、细节四视图，检查商品展示完整性与 f/8 全清设定。
13. **批量流程**：要求 8 张，检查是否先建方案/表格并等待确认，而不是未经确认自动生成。

只有完成以上真实 NOVAI 环境测试，才能称为通过原生适配验收。

## 重要适配说明

- 核心逻辑全部放在 `SKILL.md` 中，便于 NOVAI 当前的 Markdown Skill 导入器读取（`name` 需与目录名一致、`description` ≤1024 字、正文 ≤200KB，本版均满足）。
- **正文长度与 NOVAI 上限**：本版正文 21,631 字符，要求后端 `AGENT_SKILL_PROMPT_MAX_CHARS ≥ 21631`（v1.1.4 配套已把上限从 20000 提到 40000）。若装到上限仍是 2 万的后端，超出的尾部会被截断（只剩「（技能说明过长，已截断）」），此时请改用 v1.1.3 的压缩版。
- **安装版（PyInstaller 冻结包）**：内置技能包与后端上限都打进后端二进制，必须重新打包发版才在正式安装版生效；磁盘上改 `server/skills/builtin_packs/` 对已安装的 App 不生效。
- `references/` 是扩展资料；只导入 `SKILL.md` 也能完整跑通——第 5 节的镜头参数表已在主文件内。
- 不伪造真实姿势图库；需要真实图片时使用用户素材、NOVAI 素材库或联网搜图，并提示授权风险。
- 不含 Python/JS 脚本，不绕开 NOVAI 的模型配置、画布节点、任务状态与用户确认机制。
- 生成一致性取决于模型是否支持多参考图输入；Skill 要求优先使用真实参考素材并逐张审查，但不承诺百分之百一致。
- 镜头参数是摄影语言，不是 EXIF；不同模型对参数的响应不同，Skill 已写明退化写法，不向用户承诺"参数一变就一定复现"。
