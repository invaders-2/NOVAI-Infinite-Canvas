## 组合建议

- **4 张**：Hero 全身 / 正面全身 / 动态全身 / 侧面或细节。
- **5 张（电商）**：正面 / 四分之三 / 侧面 / 背面 / 细节。
- **8 张**：2 张全身、2 张半身、2 张动态、2 张近景或细节。
- **鞋类**：至少一张鞋头、一张侧面、一张后跟/鞋底可见角度；参考图没有鞋底信息时，不得凭空补造。
- **服装**：至少一张正面全身、一张侧面/背面、一张材质或结构细节。

## 使用注意

- 同一组至少覆盖 3 种景别、3 种姿势类别、2 个焦段。
- 动作要写到肢体与重心（"重心落在右腿，左腿前跨半步"），不要只写"自然站立"。
- 全身照不许裁脚；半身裁在腰线，避开手肘；近景裁在胸线。
- 任何姿势都不使用七分身裁切，不在关节处切人。
- 姿势变化不等于换装：默认锁人物 + 锁服装，只换姿势与机位。
