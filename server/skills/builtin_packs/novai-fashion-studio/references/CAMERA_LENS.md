# 镜头参数库（Camera & Lens Library）

本文件是 SKILL.md 第 5 节的扩展参考。核心原则不变：**每张镜头必须写清焦段、光圈、机位高度、距离、景深目标**，写不出这五样就等于没做摄影决策。

> 参数是给模型的"摄影语言"，不是真实 EXIF。不要向用户承诺用了 85mm 就与上次完全一致，也不要在提示词里写机身型号（容易被渲染成画面里的品牌文字）。

## 1. 焦段—景别矩阵（只允许落在 ● 的格子里）

| 焦段 | 全身 | 半身 | 近景 | 局部特写 | 远景 |
|---|---|---|---|---|---|
| 24mm | ● 带环境 | ○ 小心边缘拉伸 | ✗ 变形 | ✗ | ● |
| 35mm | ● 常用 | ● 带环境 | ✗ 变形 | ○ 勉强 | ● |
| 50mm | ● 标准 | ● 标准 | ○ | ○ | ○ |
| 85mm | ○ 退 4–5m | ● 最佳 | ● 最佳 | ✗ | ✗ |
| 135mm | ✗ 退 8m+ | ● | ● 压缩感强 | ✗ | ✗ |
| 100mm 微距 | ✗ | ○ | ○ | ● 唯一最佳 | ✗ |

● 推荐　○ 可用但有代价　✗ 不要用

判断口诀：**焦段越长，能拍的景别越小；焦段越短，能装的环境越多。** 错配最典型的两个事故：35mm 拍近景（鼻子变大、脸变形）、135mm 拍全身带环境（人退到画面外，环境全糊）。

## 2. 光圈—用途矩阵

| 光圈 | 背景 | 典型场景 |
|---|---|---|
| f/1.4 | 完全化开，只剩光斑 | 夜景情绪、霓虹街拍 |
| f/1.8–f/2 | 几乎化开 | 室内肖像、氛围大片 |
| f/2.8 | 柔但可辨 | 大片主视觉、Walk-in 街拍 |
| f/4 | 能看出空间关系 | Hybrid Hero、Lookbook |
| f/5.6 | 背景基本清楚 | 需要交代场景的全身 |
| f/8 | 全清 | 电商正面/侧面/背面全身 |
| f/11 | 全清、边缘也锐 | 产品全貌、微距细节 |

## 3. 机位高度与身体比例

| 机位 | 高度参考 | 比例效果 | 常用镜头 |
|---|---|---|---|
| 贴地 | 0–20cm | 腿被夸张拉长，鞋成主角，脸显小 | 24–35mm 鞋履/大片 |
| 膝盖 | 约 50cm | 腿长、气场足，仍可控 | 35–50mm 时尚全身 |
| 腰平 | 约 100cm | 最不失真、腿显长的平衡点 | 50mm 电商全身 |
| 胸平 | 约 130cm | 自然中性 | 50–85mm 半身 |
| 眼平 | 约 160cm | 平视、亲近 | 85mm 肖像 |
| 高机位 | 眼平 +40cm 以上 | 头大身小、压迫或可爱 | 35–50mm 创意 |

注意：机位越低，地面占画面越多，服装下摆越容易被压缩；拍下摆长的款式别用贴地机位。

## 4. 距离换算（人物在画面里多大）

| 焦段 + 景别 | 距离 | 人物占画幅高度 |
|---|---|---|
| 24mm 全身带环境 | 1.5–2.5m | 约 1/2 |
| 35mm 全身 | 2–3m | 约 2/3 |
| 50mm 全身 | 3–4m | 约 3/4 |
| 85mm 半身 | 2–3m | 约 1/2（腰以上） |
| 85mm 全身 | 4–5m | 约 3/4 |
| 135mm 近景 | 3–4m | 约 1/3（胸以上） |
| 100mm 微距 | 0.3–0.5m | 局部填满画幅 |

写距离的目的：让"人和画面外框的关系"可控。同一焦段写 2m 和写 5m，出来的人脸大小完全不一样。

## 5. 景深目标写法（三档，选一档写进去）

- **全清**：`从头顶到鞋底全部清晰，地面纹理可辨，背景结构清楚`
- **背景可辨但柔**：`焦点落在面部与领口，背景保留空间轮廓但边缘柔化`
- **背景化开**：`焦点落在眼睫毛与颧骨，背景三米外化开成色块，只留光斑走向`

不要写"大光圈虚化"这种空话，要写"哪里清楚、哪里虚、虚到什么程度"。

## 6. 品类配方速查

### 女装/男装成衣
- 正面全身 50mm f/8 腰平 3.5m 全清
- 四分之三 50mm f/8 腰平 3.5m 全清
- 侧面 85mm f/8 胸平 3m 全清
- 背面 50mm f/8 腰平 3.5m 全清
- 走动 35mm f/4 腰平 2.5m 背景可辨
- 面料细节 100mm 微距 f/8 0.4m 全清

### 鞋履
- 鞋头 100mm 微距 f/8 0.35m 全清（贴地略高机位）
- 侧身 85mm f/8 膝盖机位 2.5m 全清（显鞋侧与鞋底弧线）
- 后跟 100mm 微距 f/8 0.4m 全清
- 上脚全身 50mm f/5.6 腰平 3.5m（脚落画面下三分之一）
- 走动 35mm f/4 膝盖机位 2m（鞋不糊）

### 包袋/配饰
- 正面 85mm f/8 胸平 2m 全清
- 侧面厚度 100mm 微距 f/8 0.5m 全清
- 五金细节 100mm 微距 f/8 0.3m 全清
- 上身搭配 50mm f/4 腰平 3m 背景柔

### 美妆/护肤
- 产品特写 100mm 微距 f/11 0.3m 全清
- 手持场景 85mm f/2.8 胸平 2m 背景化开
- 使用动作 50mm f/4 胸平 2.5m 背景可辨

### 珠宝
- 单品 100mm 微距 f/11 0.25m 全清（硬光点）
- 佩戴特写 135mm f/4 眼平 1.5m 背景化开
- 整体 85mm f/8 胸平 2m 全清

## 7. 光线与色温配套（写镜头参数时顺手带上）

| 光型 | 布光 | 光比 | 色温 | 适合 |
|---|---|---|---|---|
| 棚拍柔光 | 左右 45° 双柔光箱 + 顶光 | 1:2 | 5500K | 电商标准 |
| 大柔光单灯 | 左前 45° 大柔光 + 右侧反光板 | 1:3 | 5500K | 杂志主视觉 |
| 硬光时尚 | 裸灯/蜂巢，侧前方高位 | 1:8 | 5000–5600K | 戏剧大片 |
| 窗光 | 单侧窗，纱帘柔化，另一侧白板 | 1:4 | 4800–5200K | 自然生活感 |
| 侧逆光 | 逆光勾边 + 正面反光板 | 1:3 | 3200–4200K 暖 | 户外黄昏 |
| 夜景霓虹 | 环境冷光 + 侧前暖光 | 1:6 | 混色（青橙） | 情绪夜景 |

## 8. 常见错误对照表

| 症状 | 原因 | 改法 |
|---|---|---|
| 人物脸变形、鼻子大 | 广角拍近景 | 换 85mm 或改景别到全身 |
| 八张长一个样 | 全组同一焦段同一机位 | 按第 6 节配方分配 3 个焦段 |
| 人物像贴纸，没有空间 | 只写"虚化背景" | 写机位高度 + 距离 + 背景几米外柔 |
| 腿长得不像人 | 广角 + 贴地机位叠加 | 只用其一：35mm 腰平，或 50mm 膝盖机位 |
| 鞋变形、鞋头翘 | 低机位 + 广角 | 鞋履用 85–100mm，膝盖机位 |
| 细节糊 | 光圈太大 | 细节改 f/8–f/11 |
| 电商图看不清版型 | 光圈太大 + 姿态扭曲 | 50mm f/8 腰平，正面站姿 |
| 画面里有品牌字母 | 写了 logo/型号/品牌名 | 按 NEGATIVE_LIBRARY.md 替换 |

## 9. 一句话模板（直接抄）

`镜头参数：{焦段}，{光圈}，机位{高度}，距离 {距离}，焦点落在{位置}，{景深档位描述}，全画幅质感，无镜头畸变。`

替换示例：

> 镜头参数：85mm，f/2，机位胸平，距离 2.5m，焦点落在眼睫毛与颧骨，背景三米外化开成色块，全画幅质感，无镜头畸变。
