# 文字清零库（Text-Free Library）

本文件是 SKILL.md 第 8 节的扩展参考，专门解决"生成出来的图里冒出文字、英文单词、假 Logo、错字乱码"。

## 0. 先认清机理

模型不是"看到 no text 就一定会画干净"。它画字，通常是因为提示词里出现了**会写字的名词**：

- 品牌名、杂志名、活动名（哪怕只是举例）；
- 画面结构里的文字载体：招牌、广告牌、书、报纸、菜单、屏幕、包装、标签、吊牌、地图、票根、编号牌；
- 排版类词：标题、文案、字幕、海报、排版、字体、配色方案；
- 直接的英文词：logo、brand、typography、watermark、poster、text。

**核心策略：源头不写 + 末尾明令 + 出字定点返修。** 只写负向词不加清理，命中率很低。

## 1. 标准句库（按场景挑一句，必须单独成段）

**通用最长版（默认用这句）**
> 画面中不出现任何文字、字母、数字、符号、水印、标识字样、招牌、字幕与界面元素；服装与配饰上没有可读字母，吊牌与织标是纯色无字的；背景里的招牌、书本、屏幕、包装一律虚化或替换为无可读文字的纯色块。整张图只有人和物，没有一处可辨认的字。

**纯色棚拍版（最短，适合电商）**
> 纯色无缝背景，画面中没有任何文字、字母、数字、标签、水印与界面元素，服装上没有可读字母，吊牌为纯色无字织标。

**街景版（风险最高，要双重加固）**
> 背景建筑与店铺只保留体积、色块和光斑，不出现任何招牌与店铺文字；车辆、路人、地面标识上没有任何字母与数字；整张图没有一处可辨认的字，连一角也不出现。

**细节特写版（面料/五金/鞋面）**
> 面料纹理、五金与鞋面上不出现任何字母、编号、刺绣文字与压印字样；如有标识位，表现为同色系的纯色块，无可读字母。

**恢复式强化句（返修时追加）**
> 再次强调：整张画面不允许出现任何可辨认的文字，包括背景边缘、画面四角与服装内侧；宁可用纯色块代替，也不要写字。

## 2. 提示词替换表（改写而不是删掉）

| 原始描述 | 危险等级 | 改写为 |
|---|---|---|
| 品牌 Logo 清晰可见 | 高 | 胸前一处同款小标识，纯色刺绣，无可读字母 |
| 吊牌、洗水标 | 高 | 纯色无字织标（位置与形状保持不变） |
| 街景招牌 / 广告牌 / 店招 | 高 | 虚化成光斑的深色背景板，不出现文字 |
| 菜单 / 书 / 杂志 / 报纸 | 高 | 桌面上的纯色纸张，或撤掉 |
| 手机 / 电脑 / 屏幕 / 平板 | 高 | 黑屏的纯色设备，或撤掉 |
| 包装盒 / 瓶身 / 罐体标签 | 高 | 纯色无字包装，只保留形状与材质 |
| 信用卡 / 价签 / 票根 | 高 | 撤掉，或改成纯色卡片 |
| 车牌 / 门牌 / 路牌 | 高 | 纯色平面，不出现数字与字母 |
| 海报 / 排版 / 标题 / 文案 | 极高 | 不生成海报，只做纯摄影画面 |
| 品牌 slogan / 标语 | 极高 | 本 Skill 不产出带字画面，改用海报模板 |
| 杂志封面感 | 中 | 杂志级摄影质感（不要"封面"） |
| 复古海报风 | 极高 | 改胶片质感、复古色调 |
| 品牌名 / 型号名（如某机型） | 极高 | 全画幅质感、长焦压缩感（只写视觉） |
| 涂鸦 / 街拍标语墙 | 中 | 纯色墙面或色块肌理 |

## 3. 风险分级与场景选择

| 等级 | 场景 | 出字概率 | 建议 |
|---|---|---|---|
| 低 | 纯色无缝纸、纯色背景板、白棚 | 低 | 标准句即可 |
| 中 | 室内空间、衣架、家具、桌面道具 | 中 | 道具换纯色无字，硬装装饰虚化 |
| 高 | 街景、店铺、书刊、屏幕、包装、鞋侧、刺绣 | 高 | 换纯色/虚化，或直接换场景 |

**决策建议**：电商单（要求干净可控）优先低风险场景；大片可以用中风险场景换氛围；高风险场景只在用户明确要"街头真实感"时用，并提前告知可能会出字、需要返修。

## 4. 出字后的返修话术（顺序照做）

1. **定位**："这张右下角背景板上出现了英文字母，其余都不错。"
2. **说明改法**："我把背景板换成虚化色块，并加固文字清零，只重这一张。"
3. **改提示词**：替换危险描述 + 追加恢复式强化句。
4. **重生成**：`update_node` 改提示词 → `run_generation`。
5. **换模型或换场景**：连续两张仍出字就换，不要反复硬刚。
6. **不要整组重做**：其它镜头没有文字问题就保持不动。

## 5. 常见失败案例与判断

| 现象 | 真实原因 | 处理 |
|---|---|---|
| 只改负向词，还是出字 | 源头名词没清 | 先做第 2 节替换 |
| 一张比一张字多 | 提示词越写越长，名词越堆越多 | 删描写，精简到必要信息 |
| 服装上出现品牌字母 | 写了"logo/brand/型号" | 改"纯色刺绣小标识，无可读字母" |
| 背景角落冒小字 | 街景/店铺描述 | 换纯色棚拍或虚化到色块 |
| 画面边缘有水印感 | 提示词含"水印/版权/拍摄于" | 删掉这一整句 |
| 出现乱码汉字 | 模型强行写字 | 删掉所有与"字/文本"相关的描述 |
| 鞋侧出现英文 | 鞋类参考图本身带字 | 明确"鞋侧同色系纯色块，无可读字母"，并接受可能需要局部修 |

## 6. 边界：本 Skill 不做带字画面

用户要海报、详情页、带卖点排版、带标题封面时：

- 说明本 Skill 只出纯摄影画面；
- 建议走 NOVAI 的海报/详情页模板（那边的文字由排版层生成，可编辑、不出错字）；
- 或先出图，再到设计工具里加字。

不要为了满足"加字"需求去写"画面上方写 8 个字的标题"——那是必定出乱码的路。
