# 时尚摄影与造型执行规范

## 1. 人物指导

人物指导应描述可执行动作，而不是抽象评价。至少考虑：
- 身体重心：落在哪条腿、身体是否倾斜、躯干扭转幅度；
- 手臂与手部：手的位置、弯曲角度、是否接触服装或道具；
- 头部与视线：朝向、抬低、视线落点；
- 表情：克制、疏离、坚定、松弛、冷静等，并说明强度；
- 动态：行走、转身、停顿、风吹、整理衣物等动作是否自然；
- 人物与空间：靠近、远离、倚靠、穿行、被建筑线条框定等。

动作要自然且符合服装、场景和人物关系。避免不必要的夸张扭曲和不符合人体结构的姿态。

## 2. 服装与造型

明确主造型和可选变化：
- 上装 / 下装 / 外套 / 连衣裙的廓形与比例；
- 面料视觉特征，如哑光、光泽、挺括、柔软、透明、针织纹理、皮革肌理；
- 层次与穿着方式；
- 鞋履、包袋、首饰、眼镜、帽饰等配件；
- 妆面、发型与整体人物气质。

涉及用户上传产品图时，产品结构与细节优先于创意自由发挥。不得擅自增加 / 删除纽扣、拉链、鞋带、Logo、拼接线或装饰件。

## 3. 场景规划

场景必须服务于叙事与画面构成。说明：
- 场景类型与空间尺度；
- 背景材质和主要结构；
- 前景、中景、背景的层次；
- 人物与场景的距离和互动；
- 道具的功能；
- 环境色彩与服装的关系；
- 需要清除或避免的干扰物。

## 4. 摄影构图

根据画面功能选择景别与构图：
- **环境建立镜头**：人物与空间关系明确，交代故事环境；
- **主视觉镜头**：最强识别度，构图鲜明，适合封面或 Campaign Hero；
- **全身造型镜头**：完整呈现服装轮廓、比例和鞋履；
- **人物肖像**：强调面部、神态、妆发与情绪；
- **动态镜头**：通过行走、转身、衣摆或环境运动形成瞬间感；
- **细节镜头**：呈现面料、工艺、配饰、手部和产品结构；
- **实验镜头**：利用遮挡、反射、尺度、裁切、俯仰角或空间几何制造独特表达。

不要求所有项目都包含全部类型。每张图都要说明它在系列中的作用。

## 5. 镜头与视角语言

不要根据单张参考图臆测真实器材参数。用可执行的视觉描述：
- 广角空间感 / 透视张力；
- 标准视角 / 自然比例；
- 中长焦压缩感 / 背景关系凝练；
- 近距离肖像 / 背景柔化；
- 低机位强化人物与建筑尺度；
- 高机位压缩空间或突出几何关系。

只有用户要求具体器材建议时，才给出参考焦段范围，并标注为拍摄建议，不是从图片确认的事实。

## 6. 光线方案

说明以下要素：
- 主光方向；
- 光质（硬光 / 柔光 / 透射光 / 反射光）；
- 面部补光与阴影保留；
- 轮廓光 / 背景分离；
- 环境光与色温关系；
- 高光控制和暗部层次。

用“从人物右后方形成窄轮廓光，正面以大面积柔光保留肤质层次”这类执行描述，避免只写“高级电影光”。

## 7. 后期方向

明确肤色处理、整体色温、饱和度、反差、黑位、高光滚降、颗粒、锐度和材质保留。不要默认磨皮、塑料皮肤、过度 HDR 或过度锐化。产品与服装材质必须真实可辨。
