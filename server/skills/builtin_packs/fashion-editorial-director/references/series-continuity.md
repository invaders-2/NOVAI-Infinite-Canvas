# 系列大片一致性管理规范

## 目标

让不同画面像同一个 Campaign / Editorial 项目拍摄的作品，同时保留每一张的构图、动作和叙事差异。

## 1. 建立项目连续性锁（LOCK）

在开始分镜前整理：

### 人物 LOCK
- 模特身份 / 面部特征（如用户提供人物参考图）；
- 发型、发色、妆容；
- 年龄感与气质表达；
- 身材比例只按用户提供或图像可见事实描述，不做身份推断。

### 造型 LOCK
- 核心服装及其廓形、颜色、面料、结构；
- 鞋履、包袋、配饰；
- 重要产品细节与品牌标识；
- 哪些造型允许变化，哪些必须完全不变。

### 视觉 LOCK
- 核心色彩系统；
- 摄影质感与光线基调；
- 场景美学与时代氛围；
- 画面比例与制作规格（如用户已指定）。

### 叙事 LOCK
- 主题和核心情绪；
- 故事背景；
- 人物状态与系列时间关系；
- 必须出现或禁止出现的元素。

## 2. 每张图的变量

每个镜头只改变有明确理由的变量，例如：景别、机位、人物动作、空间位置、局部光线、前景关系。不要无缘无故同时改变模特、服装、妆发、色调和场景。

## 3. 镜头差异矩阵

检查相邻镜头是否在下列至少一个主要维度上形成有意义变化：
- 景别；
- 机位 / 透视；
- 人物动作；
- 人物与环境关系；
- 画面重心；
- 叙事功能。

变化不是为了变化。全身镜头之间若只是模特稍微转头，不构成足够的镜头差异。

## 4. 图像生成一致性指令

每张提示词都应重复最重要的身份与造型锚点，不能只写“same model as previous image”。当工具支持多参考图时，说明哪张图负责身份、哪张图负责服装、哪张图负责场景；不要让模型自行猜测参考关系。

如图像生成工具支持固定 seed、角色参考、风格参考或参考强度，可在模型适配层中设置；不要假定所有模型都支持这些功能，也不要把未验证的参数写成必需条件。

## 5. 修改规则

收到局部修改时：
1. 把用户指定的修改对象列为可编辑项；
2. 其余已确认 LOCK 保持不变；
3. 若修改影响其他镜头（例如更换整组服装），先指出连带影响；
4. 用户只要求修改某一张时，默认只修改该张；
5. 更新变更摘要和版本号。
