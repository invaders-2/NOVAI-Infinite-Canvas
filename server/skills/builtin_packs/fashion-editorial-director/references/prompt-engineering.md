# AI 图像提示词工程规范

## 目标

把已确定的创意和分镜变成清楚、具体、无歧义、可独立复制的图像生成指令。提示词服务于画面，不是形容词越多越好。

## 1. 通用结构

每张图的提示词按以下逻辑组织：

1. **画面任务**：时尚 Editorial / 奢侈品牌 Campaign / Lookbook 等；
2. **主体**：模特数量、人物设定、主体位置；
3. **身份与造型**：人物参考绑定、服装廓形、面料、发型、妆容、配饰；
4. **动作与表情**：重心、肢体动作、视线和情绪；
5. **场景**：空间、背景、道具、前中后景；
6. **构图**：景别、机位、画面重心、透视、留白；
7. **摄影与光线**：镜头视觉感、景深、主光方向、光质、阴影；
8. **色彩与质感**：配色、对比、材质、皮肤与布料真实度；
9. **画幅与交付**：比例、横竖构图、主体安全区域（仅在用户有要求时）；
10. **禁止项**：产品错误、肢体错误、文字水印、无关物件等。

## 2. 具体性原则

- 用可视化动作代替抽象评价。
- 用可执行光线关系代替“电影感灯光”。
- 说明主体在画面中的位置和大小，避免只写“构图高级”。
- 服装细节尽量描述结构、材质与颜色，不使用不确定的品牌型号。
- 对真实产品，列出最重要的结构锁定项，避免模型自行改造。
- 保留必要的负面限制，不要堆叠几十个互相冲突的反向词。
- 每张图必须完整，不依赖上一张提示词。

## 3. 文生图与图生图区分

### 文生图

重点写清楚主体、造型、场景、构图、光线与摄影质感。没有人物参考时，不宣称人物与某张图一致。

### 图生图 / 多参考图

必须包含 Reference Mapping：
- REF-A：人物身份 / 脸部 / 发型；
- REF-B：服装 / 产品结构；
- REF-C：场景 / 构图；
- REF-D：光影 / 色调。

按用户给定的实际参考图填写，并说明主次。参考角色不存在时不虚构编号。

## 4. 中英文版本

默认提供中文和英文两版。英文版不是逐字硬翻，而应保持相同的画面结构与约束。两版不得出现不同的服装、动作、颜色或场景设定。

## 5. 负面提示词

根据任务选择必要限制：
- anatomical errors / distorted hands / extra fingers / malformed limbs；
- duplicated people / duplicate accessories；
- incorrect garment construction / missing details / extra buttons / altered logo；
- plastic skin / excessive retouching / fake fabric texture；
- random text / watermark / unintended logo；
- cluttered background / unwanted props / inconsistent lighting。

不能机械地把所有负面词都放进每张图。优先使用与本项目具体风险相关的限制。

## 6. 画幅与参数

用户没有指定画幅时，不强行猜测。用户指定 4:5、3:4、1:1、16:9 等时，在提示词和输出说明中明确写出。分辨率、采样器、CFG、步数、参考权重等参数因模型而异；只有在确认目标模型时才提供对应参数，并将不确定项标记为建议值。

## 7. 提示词验收

一条合格提示词应使执行者不必再翻阅整份策划书，也能理解该画面应该如何生成。检查：主体是否明确、动作是否明确、场景是否明确、构图是否明确、光影是否明确、连续性是否明确、限制是否明确。
