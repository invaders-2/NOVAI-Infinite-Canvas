# 时尚大片方案质量审核 Gate

交付前进行以下检查。存在关键缺陷时先修复，不要把不完整方案交给用户。

## A. 参考图分析 Gate

- [ ] 所有收到的图片都已分配 REF 编号。
- [ ] 用户指定的参考角色没有搞错。
- [ ] 可见事实、视觉推断、创意建议彼此区分。
- [ ] 构图、造型、场景、色彩、光影和摄影语言有具体分析。
- [ ] 多图冲突已明确说明并处理。

## B. 创意 Gate

- [ ] 有清晰的一句话创意主张。
- [ ] 创意与用户产品 / 主题相关，而非套用通用风格。
- [ ] 至少有一个可记忆的视觉亮点。
- [ ] 场景、人物、服装、色彩、动作和光线支持同一创意。
- [ ] 不是简单复制参考图。

## C. 摄影 Gate

- [ ] 每张图的叙事功能明确。
- [ ] 镜头之间有足够的景别、构图或动作差异。
- [ ] 模特动作自然、可执行。
- [ ] 光线描述可执行。
- [ ] 产品或服装关键细节得到保护。

## D. 连续性 Gate

- [ ] 人物身份与妆发锁定清晰。
- [ ] 服装和产品锁定项清晰。
- [ ] 色彩与摄影基调一致。
- [ ] 镜头变化没有破坏已确认的项目设定。

## E. 提示词 Gate

- [ ] 每张图都有独立完整的提示词。
- [ ] 参考图绑定关系明确。
- [ ] 中英文版本含义一致（如提供双语）。
- [ ] 负面约束针对实际风险。
- [ ] 没有未经确认的模型专属参数。

## F. 表达 Gate

- [ ] 没有用空洞形容词代替画面描述。
- [ ] 没有冗长重复的解释。
- [ ] 假设与未确定信息已明确标注。
- [ ] 用户要求的输出格式、张数和画幅已遵守。

## 交付等级

- **PASS**：关键要求齐全，可进入制作。
- **PASS WITH NOTES**：主体方案完整，但有少量假设或待确认事项；必须列明。
- **BLOCKED**：缺少会导致方案方向错误的关键信息，或无法读取用户要求分析的图片；说明具体阻塞点并提出最小补充需求。
