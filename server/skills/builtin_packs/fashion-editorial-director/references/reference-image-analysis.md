# 参考图深度分析规范

## 目标

把参考图从“感觉像什么”拆解成可供创意和摄影执行使用的视觉信息。分析应具体、可追溯，并区分图像事实、视觉推断和创意建议。

## 1. 图片登记

每张图片分配唯一编号：`REF-01`、`REF-02`……。记录用户指定用途；如果用户未指定，先判断最明显的参考维度并标注为“初步判断，待确认”。

建议登记字段：
- 图片编号；
- 用户指定用途；
- 主体类别（人物 / 服装 / 产品 / 场景 / 摄影风格 / 构图 / 色彩 / 光影）；
- 主体与环境关系；
- 主要视觉信息；
- 可借鉴内容；
- 不应沿用的内容；
- 信息可信度与不确定点。

## 2. 分析维度

### A. 整体视觉定位

判断属于哪类视觉表达：奢侈品 Campaign、杂志 Editorial、设计师 Lookbook、商业时装摄影、街头时尚、极简棚拍、概念艺术时尚、运动时尚等。可同时包含多个维度，但要指出主次。说明画面偏向品牌传播、人物表达、服装展示还是叙事表达。

### B. 人物与肢体语言

观察人物数量、画面位置、身体朝向、重心、四肢状态、手部动作、头部角度、视线方向、表情强度、人物与环境互动。不要仅写“模特自然、姿态高级”；要说明身体怎样形成线条、张力与视觉动势。

### C. 服装与造型

观察服装廓形、层次、结构线、长度比例、面料表面、垂坠状态、褶皱、光泽、透明度、配色、鞋履和配饰。若产品细节很重要，明确可见细节与需要用户补充的细节，不猜测品牌、材质成分或型号。

### D. 场景与空间

分析室内 / 室外、真实场景 / 棚拍 / 搭景、空间深度、背景纹理、建筑线条、前中后景、道具、环境与人物关系、环境是否承担叙事功能。

### E. 构图与视觉动线

分析景别（特写、近景、中景、全身、远景）、主体位置、画面重心、对称 / 非对称、留白、框景、前景遮挡、引导线、负空间、画面边缘关系、地平线与透视。注意判断横竖画幅以及主体是否被裁切。

### F. 色彩与明暗

提取主色、辅助色、点缀色与中性色；说明色彩面积关系、冷暖关系、饱和度、明度、对比度，以及色彩是否服务于服装或品牌识别。避免没有图像采样依据时给出伪精确色值。

### G. 光影

判断主光大致方向、光质（硬 / 柔）、光比、轮廓光、环境光、反射、高光控制、阴影形态、曝光倾向。光源位置只能作视觉估计，不能断言现场灯具数量与型号。

### H. 摄影语言与质感

分析视角高度、透视感、景深、背景虚化、运动模糊、颗粒、锐度、肤质、材质呈现、动态范围和后期处理。焦段、相机、镜头型号无法由单张图可靠确认，使用“类似中长焦压缩感”“广角空间张力”等视觉语言，并标注为推断。

### I. 情绪与叙事

识别画面传递的情绪、人物关系、时间感、空间氛围、潜在故事。避免把个人联想写成图片的客观设定。

## 3. 多参考图融合矩阵

多图时必须制作一张融合矩阵：

| 图片 | 主要用途 | 保留 / 借鉴 | 改造方式 | 明确排除 |
|---|---|---|---|---|
| REF-01 | 人物气质 | 人物年龄感、神态、姿态语言 | 转换到新场景和新服装 | 原图背景与具体摆位 |
| REF-02 | 服装 | 轮廓、材质、配色、关键细节 | 按产品实际结构呈现 | 参考图中不属于本产品的配件 |
| REF-03 | 摄影 | 光线方向、构图逻辑、色调 | 改为适配本次故事的景别 | 不适合主题的道具与背景 |

表格内容必须根据实际图片填写，不得把上例作为固定结论。

## 4. 冲突解决原则

优先级从高到低：
1. 用户在本轮明确提出的要求；
2. 用户明确锁定的产品 / 人物 / 服装事实；
3. 用户给每张参考图指定的作用；
4. 项目已确认的连续性设定；
5. AI 对参考图的推断与建议。

如果不同参考图在人物、服装、色调或场景上明显冲突，先指出冲突，再提出融合策略；不要默默把矛盾细节拼接成不合理画面。

## 5. 分析报告格式

每张图按以下结构输出：

- **REF 编号 / 用户用途**
- **整体判断**
- **可见事实**
- **视觉推断（注明不确定性）**
- **人物与造型**
- **场景与构图**
- **色彩与光影**
- **摄影语言**
- **值得借鉴的 3–5 个要点**
- **不建议直接照搬的内容**
- **对本项目的创意启发**

总结时说明：本次项目最值得提取的是哪几个视觉方法，如何重新组织成原创画面。
