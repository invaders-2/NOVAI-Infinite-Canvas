# 标题变体

> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
用科学的 A/B 测试跑出最高转化：固定好视觉与版面，从焦虑唤醒、限时利益、社交认同等多心理维度快速生成对比标题，助你找到最优解。
锁定跑量素材的高点击画面，批量裂变不同痛点与卖点文案，低成本测出 CTR 翻倍的爆款标题。

## 适用场景
- 固定产品、优惠、画面和构图，只改变标题角度，生成可比较的测试变体。

## 工作步骤
1. 锁定控制组：保持产品、图片、优惠、CTA、排版和版位不变。
2. 撰写不同标题：每个变体只测试一个有依据的假设，提供准确换行。
3. 排入准确文字：保留控制组像素；无法精确排版时，交付文案与排版方案。

## 交付物
- 受控标题假设、准确文案和换行方案
- 保留标题区域外像素的变体，或文案排版包

## 边界
- 不会重做广告、做市场本地化、改版位比例，也不会一次改变多个说服变量。

## 需要准备
- 开始前准备：准备控制组广告、产品与优惠事实、受众、可编辑文案、品牌语气、测试数量和成功指标。
