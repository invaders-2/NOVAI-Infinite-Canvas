# 开头钩子测试

> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
前 3 秒决定一条视频的生死：在不重新拍摄整条广告的前提下，快速生成提问悬念、视觉反差或痛点直击等不同开头变体，快速测出爆款率。
保留原视频主体与转化结尾，批量替换前 3 秒黄金抓人开头，低成本拯救完播率与 ROI。

## 适用场景
- 只改变开头钩子，保留已批准的正文、优惠、CTA 和结尾，生成完整可比较的电商视频变体。

## 工作步骤
1. 确认钩子边界：标出开头结束、保留正文开始的准确位置。
2. 每次测试一个思路：设计有依据的开头，写清接入时间和音频过渡。
3. 检查衔接：支持剪辑时交付完整变体，否则明确交付钩子片段与剪辑方案。

## 交付物
- 钩子变体假设、源视频接入时间与音频过渡方案
- 支持剪辑时交付完整变体，否则交付钩子片段与剪辑方案

## 边界
- 如果没有可用的完整剪辑能力，会明确交付钩子片段和装配方案，不把片段称作完整变体。

## 需要准备
- 开始前准备：准备控制组视频、源时间码、钩子边界、共用正文与结尾、产品事实、变体数量、发布场景和音频约束。
