# 3D片场 2.0

> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
用 Agent 创建和编辑 3D 场景、角色、灯光与运镜，在一个片场里完成从预演到成片的规划。

## 适用场景
- 用自然语言创建可编辑的 3D 场景
- 让 Agent 持续调整角色、环境、灯光与运镜
- 在生成成片前先预览并确认场景方案

## 工作步骤
1. 描述场景目标：告诉 Agent 要创建什么，包括主体、环境、风格、灯光和镜头意图。
2. 让 Agent 完成首版：Agent 会把描述变成可编辑的 3D 场景，并展示环境、角色、灯光和运镜的首轮方案。
3. 通过对话持续编辑：直接提出场景、材质、灯光、调度或运镜的具体修改，并逐轮确认结果。

## 交付物
- 根据描述创建的可编辑 3D 场景
- 持续迭代后的角色、环境、灯光与运镜

## 边界
（上游未公开）

## 需要准备
- 描述你想搭建的场景：告诉 Agent 主体、环境、视觉风格、灯光和镜头意图，Agent 会先搭出可编辑的 3D 场景，再根据对话继续修改。

## 起手提示
用 Agent 创建和编辑一个 3D 场景，加入角色、灯光和运镜。
