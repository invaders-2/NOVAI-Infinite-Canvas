## 定位
顶级创意的实验场：汇集 3D、动效与视觉艺术的边界玩法。

## 适用场景
- 成片前先做白模预演
- 把静帧重建成可预览的 3D 场景
- 保留原片运动，迁移角色或场景外观

## 工作步骤
1. 选玩法：按你要解决的是场面、空间还是运动迁移，选择白模、图片3D或深度影视。
2. 准备输入：白模需要画面创意，3D需要参考图，深度需要源视频与外观参考。
3. 直接试玩：每个用例都会打开对应官方 Skill 的草稿，可马上开跑。

## 交付物
- 可播放的白模预演
- 可旋转预览的 3D 场景
- 保留运动的深度重塑成片
