# 跨平台内容复用器

> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
一条长视频、播客或文章，先拆成 3–7 条能单独发布的内容，再分别适配 Instagram、TikTok、LinkedIn 和 Shorts。
同一份素材，变成多条真正适合各平台的内容。

## 适用场景
- 找出最值得做成帖子的重点
- 把每个重点改成适合它的平台内容

## 工作步骤
1. 先保住源素材：拆解前确认事实、使用权和 master 素材。
2. 挑出值得保留的重点：找出 3–7 个离开上下文也能讲清楚的内容。
3. 让每个重点适合自己的平台：按平台改钩子、格式、节奏、CTA 和安全区。
4. 把整套内容过一遍：逐条检查说法、裁切、时长、披露、权利和改动了什么。

## 交付物
- 按优先级排列的 3–7 个独立重点
- 平台原生脚本、字幕、封面、短片方向和 CTA
- 一张简单对比表：来源、平台、时长和每条内容改了什么

## 边界
- 我会在画布里先做草稿和检查过的素材包；什么时候发布或排期，由你最后确认。
- 我只使用你提供并确认过的事实和使用权；没有依据的说法、私密信息或披露不清的内容会停在审阅。
- 每段生成的短视频最长 5 秒；更长的故事需要拆成已确认的片段，或交给独立剪辑流程。
- 页面能打开或请求成功，不代表一定能发布或一定有效果；交付前请看完最终素材包。

## 需要准备
- 长素材是什么？：提供视频、播客、文章、逐字稿或录音。
- 你想让谁看到？：说清受众、目标，以及最好的几条内容希望换来的动作。
- 重点发到哪些平台？：选择 Instagram、TikTok、LinkedIn、YouTube Shorts，或四个平台都要。
- 交付要满足什么？：写明语言、语气、画幅、版本数量、截止时间和披露要求；单段生成短视频最长 5 秒。
