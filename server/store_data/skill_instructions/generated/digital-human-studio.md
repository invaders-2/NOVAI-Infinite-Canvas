> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
专属数字人随时登台，一条搞定全场景。

## 适用场景
- 为短视频平台制作稳定、自然的数字人口播
- 用数字人带观众快速看懂一套房源
- 让数字人把产品价值、用法和试用动作讲清楚
- 把专业知识讲成清晰易懂的数字人课程
- 用有时间边界的事实做一条新闻播报
- 先建立可复用的角色形象与声音资产

## 工作步骤
1. 选择玩法：按最终目标选择社媒口播、房产带看、产品演示、知识科普讲解、市场播报或角色工坊。
2. 补充 brief：提供事实、受众、来源资料和希望观众完成的下一步。
3. 直接试用：五个视频玩法会用同一个数字人演播厅 Skill 打开聊天草稿；角色工坊进入独立的角色设定流程。

## 交付物
- 一条聚焦目标的数字人视频草稿
- 选择角色工坊时得到一套可复用的角色身份设定

## 边界
- 六个详情页是同一个远端 Skill 的不同入口，不会创建六个独立运行时 Skill。

## 需要准备
- 先选玩法：先看最终要让观众完成什么，再用平台、时长和画幅细化 brief。
