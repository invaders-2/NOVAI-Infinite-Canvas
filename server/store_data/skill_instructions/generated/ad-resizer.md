# 尺寸适配器

> 说明：本技能为官方技能，原始执行手册未随客户端下发，以下内容由公开元数据整理，非原文。

## 定位
告别手动切图改尺寸的机械劳动：智能识别主体、卖点文案与 CTA 按钮，为各平台信息流与故事版位自动重构最佳构图与安全区。
上传单张定稿海报，智能重构 1:1、4:5、9:16 与横幅等多渠道版位，画面绝不生硬拉伸。

## 适用场景
- 把已批准的静态广告重排成 1:1、4:5、9:16 和横幅等适合版位的构图。

## 工作步骤
1. 锁定源广告：明确要保护的产品细节、文案、logo 和目标版位。
2. 逐版位重排：安排产品大小、裁切、换行、CTA 和平台安全区。
3. 检查两种观看尺度：同时检查大图和缩略图，再交付各比例版本。

## 交付物
- 各版位重排方案与源广告不变量清单
- 多比例素材与安全区检查结果

## 边界
- 不会改变产品几何、编造周边细节，也不会把居中裁切直接当成成稿。

## 需要准备
- 开始前准备：准备源广告、产品与 logo 素材、目标比例、安全区、裁切优先级和不可变信息。
