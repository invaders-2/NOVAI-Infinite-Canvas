## 定位
体验用代码生成视频的惊艳和乐趣，再把一个想法带入Icon动画制作、动态文字视频设计、商品视频、知识内容、动态播报或 3D 场景。
体验代码生成视频的惊艳和乐趣，用 Opus 5.5 把想法变成可查看的动效。

## 适用场景
- 动态文字视频设计
- Icon动画制作
- 知识科普讲解
- YouTube 商品视频
- 新闻播报
- 3D片场 2.0

## 工作步骤
1. 锁定玩法和证据：先选一个玩法，检查输入与版权，在写代码前完成 brief、节拍表或场景图。
2. 构建确定性预览：使用固定 FPS 和 seek(t) 或等价的可复现状态，保留准确文案与素材身份。
3. 检查并说明状态：完成 contact sheet、关键帧、console、窄屏和音频/交互检查，明确说明已验证内容。

## 交付物
- 聚焦的 brief 与验收清单
- 所选工作流可继续评审的第一版
- 可进入画布继续修改且边界清晰的结果

## 边界
- 入口一次只路由到一个现有市场工作流。
- 被选中的子工作流保留自己的输入输出契约。
- 从该入口启动聊天类工作流时，Agent 使用 Opus 5.5。

## 需要准备
- 准备 brief 和真实素材：提供准确文案、源视频或世界观规则、真实参考、目标时长/FPS/比例和版权信息。
- 先选一个结果状态：明确需要 HTML 预览、EDL/渲染计划还是已验证 MP4。
- 写下验收标准：指定让结果可用的画面、交互、字幕、节奏、音频或交接检查。
